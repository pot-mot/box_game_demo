# 受击硬直

> 共用规范见 [`动作设计规范.md`](../../../../../../../../docs/bone_animation/动作设计规范.md)。
> 状态：当前实现（肘反向）。

## 状态

- 状态 `flinching`，基础时长 `FLINCH_DURATION = 0.1s`（`src/character/combat/attack_phases.ts`）；重击使用 `HEAVY_FLINCH_DURATION`，非循环 clamp。
- clip 由 `pose_fns.ts` 的 `flinchingPose` 烘焙；`p = clamp01(t / 0.1)`，`e = 1 - (1 - p)³`。

## 涉及关节

`spine`、`headNeck`、`rightArmShoulder`、`rightArmElbow`、`leftArmShoulder`、`leftArmElbow`。

## 当前参数

| 关节 | 表达式 |
|---|---|
| `spine.rx` | `-FLINCH_SPINE_BACK · e`（`0.25`，负值 = 后仰） |
| `headNeck.rx` | `-FLINCH_HEAD_BACK · e`（`0.15`） |
| `rightArmShoulder.rx` | `-FLINCH_ARM_RAISE · e`（`0.9`，前抬护头） |
| `leftArmShoulder.rx` | 同 |
| `rightArmShoulder.rz` | `+FLINCH_ARM_SPREAD · e`（`0.5`，向 `+X`） |
| `leftArmShoulder.rz` | `-FLINCH_ARM_SPREAD · e`（镜像） |
| `rightArmElbow.rx` | `FLINCH_ELBOW · e`（`-1.2`，负值 = 前折） |
| `leftArmElbow.rx` | 同 |

## 修正记录

- 肘由 `+1.2` 改为 `-1.2`：肩前抬的同时前臂向前折，肘尖朝后下，护头姿态自然。
- 受击为 0.1s 瞬态，**不做腕补偿**（武器随臂自然弹开；加补偿会引入大幅度腕旋转且无必要）。

## 验收

骨骼动画模式选择「受击硬直」，从角色 `+X` 侧观察：双臂上抬护头，肘尖朝后下、前臂向前上折。
