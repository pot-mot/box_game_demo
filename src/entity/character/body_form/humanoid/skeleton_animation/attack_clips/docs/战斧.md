# 战斧


> 共用规范见 [`动作设计规范.md`](../../../../../../../../docs/bone_animation/动作设计规范.md)；三模式连段总表见 [`持握模式动作.md`](持握模式动作.md)。
> 状态：**已实现**（双持主设计形态）。

## 武器配置

- id `dual_axe`，中文名「战斧」，`type: melee`（`melee_weapon.ts`）。
- 持握模式：`attackModules = ['one_handed','two_handed','dual_wield']`，默认单持；**双持需副手装备同类武器**（`dual_axe`）。
- 主手网格 `mesh: {id: 'dual_axe', bladeSize: 0.3, ...}`；副手网格由副手装备槽提供（同类默认模型，与主手同网格）。
- 网格 `genDualAxe` 生成**单刃斧**（柄 + 一片斧刃，刃接柄顶）；刃面立于本地 Y-Z 平面（宽沿本地 `Z`、薄沿本地 `X`）。该几何关于本地 `X` 轴对称，左手武器即右手武器关于角色矢状面的镜像，故副手不再做额外翻转。

## 攻击动作

- 地面 4 个段（轻 1 / 轻 2 / 重 1 / 重 2）+ 空中 `air_1` 的双持段，副手与主手**同帧完全镜像**：左肩 / 左肘 / 左武器骨骼逐帧由右臂关键帧按 `(rx, -ry, -rz)` 生成，不再有相位延迟。数据已烘焙进 `attack_clips/`。
- 命中事件按槽分组：主手一对（`params.slotKey: 'weapon:main_hand'`），副手一对（`'weapon:off_hand'`）；近战执行器分别开关左右命中箱，**两只手都会结算伤害**。

- 展示模式战斧角色双手各持一把斧，双持段左右斧同帧镜像挥砍；

## 动作节奏（三段式）

每段五关键帧：**t=0 持械戒备 → 抬手帧双手镜像上举 → 挥击帧左右斧同帧下劈 → 随挥帧镜像收势 → 末帧回戒备**。左臂三轨（肩 / 肘 / 武器骨骼）逐帧由右臂镜像生成，两把斧同时进入命中；节奏为抬手 : 挥击 : 后摇 = 2 : 1 : 2.5（轻段 0.4 + 0.2 + 0.5s、重段 0.48 + 0.24 + 0.6s），命中窗口主副手同帧：轻段 0.5/0.59s、重段 0.6/0.708s。

| 段 | 动作（主手/副手） |
|---|---|
| `dual_axe_dual_wield_light_1` | 双手镜像上举 → 左右斧同帧前下劈 |
| `dual_axe_dual_wield_light_2` | 双手镜像上举 → 左右斧同帧外斜下劈（与第一段落点相反） |
| `dual_axe_dual_wield_heavy_1` | 双手高位镜像上举 → 左右斧同帧重劈（幅度更大、躯干拧转更多） |
| `dual_axe_dual_wield_heavy_2` | 同重 1 的同帧镜像结构，两侧落点与末姿势区分 |

修订关键帧见 `src/entity/character/body_form/humanoid/skeleton_animation/attack_clips/`；战斧主、副武器各自以柄中心对齐左右手挂点，继续使用分槽命中事件。

## 起手抬斧约束

- 全部地面轻 / 重与空中起手帧：肩关节左右张开 `rz` 限制在 `±0.15rad`（单持同样适用），并在原作者抬手角基础上额外增加约 `0.25rad` 上抬（`rx` 更负），使斧头举得更高、左右张开更小。
- 只改肩 `rz` / `rx`，保留肘弯、腕与武器骨骼；双持副手保持同帧镜像的抬手与攻击力量。

## 三持握模式（逐模式连段）

| 模式 | 段前缀 | 动作轨迹 |
|---|---|---|
| 单持（默认） | `dual_axe_one_handed_*` | 单手斧劈 / 外斜劈 / 重劈 / 斜重劈（右臂沿用双持右手动作，左臂平衡） |
| 双手共持 | `dual_axe_two_handed_*` | 双手斧劈 / 双手斜劈 / 横扫 / 重劈（斧刃朝下，武器骨骼 3.1~3.45） |
| 双持 | `dual_axe_dual_wield_*` | 上表左右斧同帧镜像下劈 |

单持/双手段由模板族精修为战斧专属斧刃朝向（per-weapon patch），双持段为原有手工链；全部段可在骨骼动画编辑器按「战斧 · 模式 · 段名」逐段调姿势。
