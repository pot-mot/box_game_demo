# 长枪


> 共用规范见 [`动作设计规范.md`](../../../../../../../../docs/bone_animation/动作设计规范.md)；三模式连段总表见 [`持握模式动作.md`](持握模式动作.md)。

## 武器配置与握持

- id `spear`，中文名「长枪」，`attackModules` 三模式（默认单持；**双手共持为主设计形态**），枪杆沿本地 `+Y` 延伸。
- 主握点位于枪杆**中点**（`poleLen × 0.5`）；左手副握点在主握点前方 `poleLen × 0.14`（`supportGripOffset = 0.14`，按“相对主握点的距离”解析）。
- 两个握点都按枪杆本地坐标定位，武器模型原点校正后主手握点落在右手挂点；待机 / 行走 / 攻击后摇均回到中点握持。

## 攻击段（当前实现：枪轴朝目标）

**t=0 持械戒备 → 抬手帧（后引/蓄力）→ 挥击帧 = 刺出完成（枪轴指向打击方向）→ 末帧 = 持械戒备**；枪头朝向由武器骨骼承担，收招回到中点握持。节奏为抬手 : 挥击 : 后摇 = 2 : 1 : 2.5（轻段 0.4 + 0.2 + 0.5s、重段 0.48 + 0.24 + 0.6s），命中窗口轻段 on 0.5s / off 0.59s、重段 on 0.6s / off 0.708s。

**手臂防穿模**：全部攻击关键帧的左右肩 `rz` 固定向身体外侧展开（右 `-0.45`、左 `+0.45`），肘 / 手保持在躯干包围盒外；双手段左肘烘焙时使用更高的外展权重（`supportElbowOutwardOf('spear') = 3`）。

| 段 id | 动作 |
|---|---|
| `spear_two_handed_light_1` | 持枪手前推、枪尖平刺出 |
| `spear_two_handed_light_2` | 从侧向出手的短刺，落点与轻 1 区分 |
| `spear_two_handed_heavy_1` | 双手前递重刺，打击帧枪轴完全朝正前方 |
| `spear_two_handed_heavy_2` | 起手完全朝前 → 向下刺出 → 向上挑起（新增 0.96s 挑枪关键帧） |

关键姿势见 `src/entity/character/body_form/humanoid/skeleton_animation/attack_clips/`。双手副手姿态由关键帧直接编排（参考 `weaponSupportGripOffset`），双手共持段由离线烘焙支撑手双轨贴合；生产运行时不做 IK 求解。

## 三持握模式（逐模式连段）

| 模式 | 段前缀 | 动作轨迹 |
|---|---|---|
| 单持（默认） | `spear_one_handed_*` | 单手平刺 / 单手侧刺 / 单手重刺 / 单手下刺上挑（侧身枪架：根侧转 0.38 rad + 下肢错步；左臂外展平衡） |
| 双手共持 | `spear_two_handed_*` | 上表四段 + 空中段（含蓄力深刺；侧身枪架：根侧转 0.5 rad，手臂外展避躯干） |
| 双持 | `spear_dual_wield_*` | 右手枪刺 / 侧刺 / 重刺 / 下刺上挑；左手滞后约 0.25s（轻）/ 0.30s（重）镜像（侧身枪架：根侧转 0.28 rad） |

三模式均采用**侧身枪架**消除手臂-躯干穿模：`root` 关节绕 `+Y` 侧转、`spine` 反向拧转抵消（净胸口偏角约 0.1 rad）、下肢错步（前腿 `rx < 0`）；收招帧根/下肢回零与 idle 衔接。单持/双持段由模板族精修为长枪专属枪轴朝向，双手链为原有手工数据叠加侧身；全部段可在骨骼动画编辑器按「长枪 · 模式 · 段名」逐段调姿势。

## 验收

在骨骼动画模式检查地面四段（轻 1 / 轻 2 / 重 1 / 重 2）与空中段：待机 / 后摇主手握枪杆中点；重 1 打击帧枪轴完全朝正前方；重 2 依次朝前、向下、向上；左右肘 / 手在躯干包围盒外，不再穿模。`skeleton_animation/system.test.ts` 逐帧锁定副握残差 < 视觉容忍范围。
