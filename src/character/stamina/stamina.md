# 体力（character/stamina/）模块约定

> 状态：当前实现。
> 体力是角色级资源：基础配置记录在 `CharacterConfig.stamina`，运行时权威值在 `CharacterState.stamina`。

## 约定

- **唯一权威**：当前体力、上限、有效消耗、有效恢复、恢复延迟计时只存于 `entity.state.stamina`；禁止在实体 / 状态机 / 面板另存副本。
- **基础属性在角色上**：`CharacterConfig.stamina` 保存面板可编辑的基础值（缺省逐项回退 `constants.ts`）：
  - `max`：上限，默认 `5`；
  - `regenDelay`：扣除后开始恢复的延迟，默认 `0.5s`；
  - `regenPerSec`：延迟后每秒恢复，默认 `2/s`；
  - `entryCost.{attack,roll,jump}`：进入一次性动作状态的消耗，默认 `0.5/次`；
  - `drainPerSec.{sprinting,flying,blocking}`：持续状态每秒消耗，默认 `0.2/s`。
- **装备 / 武器修正**：`StaminaModifierSet` 挂在 `EquipmentStats.stamina` 与武器类 `stamina` 上，均按**乘区**逐项相乘（1 = 无修正）。有效消耗 / 恢复 = 基础值 × 全部已装备武器 + 护甲 / 肢体修正。装备变更后由世界层调用 `refreshStaminaProfile` 重算，当前体力与延迟计时保留。
- **扣除时机**：
  - 一次性动作（攻击段、翻滚、跳跃）在**进入时**扣除；攻击连段每进入一个新段扣除一次。体力不足时状态机转换守卫拒绝进入。
  - 持续状态（跑步 / 飞行 / 持盾格挡）按固定物理步时间扣除；体力归零时状态机立即退出该状态。跑步 / 格挡耗尽退出后，需恢复到上限的 `10%` 才能再次进入，避免按住按键在恢复首帧反复进出（飞行需重新双击，天然无此问题）。
  - 任何扣除都会重置恢复延迟；延迟结束前不恢复。
- **面板**：全部数值按「结果 | (基础值 + 加值) × 逐项乘区」展示；消耗 / 恢复行的乘区来源逐项列出武器与装备名。当前体力是状态行的可编辑「当前值」。

## 文件

| 文件 | 内容 |
|---|---|
| `types.ts` | 消耗分类、基础配置、装备修正、运行时子域 |
| `constants.ts` | 全部默认值 |
| `runtime.ts` | 配置解析、修正汇总、创建 / 刷新、扣除与恢复 |
| `runtime.test.ts` | 默认回退、乘区合并、装备重算、扣除 / 恢复 |

## 陷阱

- 跑步 / 飞行 / 格挡的扣除发生在**当前状态**上：状态机每物理步先 `updateStamina` 再检查转换，因此体力归零当帧即触发退出，不会多扣一帧。
- 装备修正只在装备 / 武器 / 体形 / 基础配置变化时重算；不要逐帧重新汇总。
- 旧存档缺 `stamina` / `flightEnabled` 时安全回退默认（满体力、不可飞行）。
