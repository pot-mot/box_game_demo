# 巨剑

> 共用规范见 [`动作设计规范.md`](../../../../docs/bone_animation/动作设计规范.md)。
> 状态：**已修正**（双手共持：副手姿态由动作数据独立驱动；不再自动求解支撑手 IK）。

## 武器配置

- id `heavy_sword`，中文名「巨剑」，`type: melee`，三模式（默认单持；**双手共持为主设计形态**，轻链三段）。三模式连段总表见 [`持握模式动作.md`](持握模式动作.md)。
- 网格：`{id: 'heavy_sword', bladeLen: 0.65}`；无副手网格。
- 轻链 3 段（`light_1` 竖劈 / `light_2` 直刺 / `light_3` 上挑斜斩，循环）+ 重链 2 段（`heavy_1` 横斩 / `heavy_2` 斜劈）。

## 双手共持修正记录

> 历史记录：早期曾用运行时支撑手 IK 把左手拉到握把。该机制已移除；当前双手共持的副手姿态必须由动作数据直接编排。

**当前要求**：
1. 副手关键帧直接摆到主手握把附近（参考 `weaponSupportGripOffset`）；
2. 各段关键帧保持主手肘屈起，避免武器超出副手臂展；
3. 需要反向驱动手臂时，在骨骼编辑器给末端节点配置节点 IK（CCD / FABRIK + 父级段数）。

## 验收

展示模式或骨骼动画模式播放巨剑攻击：副手随动作数据保持在握把附近，不再依赖运行时 IK 兜底。

## 本轮动作重构（三段式，已验收）

**t=0 持械戒备 → 抬手帧（满后引）→ 挥击帧 = 打击完成 → 末帧 = 持械戒备**；挥砍平面由武器骨骼承担，节奏为抬手 : 挥击 : 后摇 = 2 : 1 : 2.5（轻段 0.4 + 0.2 + 0.5s、重段 0.48 + 0.24 + 0.6s），命中窗口对齐挥击阶段（轻段 on 0.5s / off 0.59s；重段 on 0.6s / off 0.708s）。双手姿势的关键约束：**每个关键帧（含插值路径）左肩→副握点 ≤ 0.34m**，因此双手收向身体中线、躯干前倾带出打击距离；副手姿态由关键帧直接保证。

| 段 | 动作（起手 → 打击完成） |
|---|---|
| `heavy_sword_two_handed_light_1` | 头顶竖举（双手近额前）→ 前下劈，剑尖落到腹前 |
| `heavy_sword_two_handed_light_2` | 撤手蓄力 → 双手前刺（躯干前倾） |
| `heavy_sword_two_handed_light_3` | 低位后引（剑尖朝前下）→ 上挑斜斩至右上 |
| `heavy_sword_two_handed_heavy_1` | 右肩上方横举 → 横扫过中线 |
| `heavy_sword_two_handed_heavy_2` | 高位竖举 → 斜劈至左前下 |

姿势关键帧见 `src/character/weapon/attack_pose_edits.ts`。当前巨剑模型主握点在握柄中心，左手副握点沿武器本地 `+Y` 与主手错开 `0.065m`；`TWO_HAND_GRIP_OFFSET` 仅为额外微调，不再承担把主、副手从同一点分开的职责。

## 三持握模式（逐模式连段）

| 模式 | 段前缀 | 动作轨迹 |
|---|---|---|
| 单持（默认） | `heavy_sword_one_handed_*` | 单手重劈 / 单手前刺 / 单手横扫 / 单手斜劈（**外侧挥砍**：肩 `rz` 为正、手臂在身体外侧，避免横穿躯干；左臂反向平衡） |
| 双手共持 | `heavy_sword_two_handed_*` | 上表五段（轻链三段） |
| 双持 | `heavy_sword_dual_wield_*` | 右手外侧重劈 / 前刺 / 横扫 / 斜劈；左手滞后约 0.25s（轻）/ 0.30s（重）镜像（外侧摆幅、肘更屈 -0.15） |

单持/双持段由模板族精修为巨剑专属幅度（per-weapon patch），双手段为原有手工链；全部段可在骨骼动画编辑器按「巨剑 · 模式 · 段名」逐段调姿势。
