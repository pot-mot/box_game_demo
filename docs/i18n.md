# 国际化（i18n）系统

> 目标：全量 UI 文案（含游戏数据名称）支持简体中文（`zh-cn`）与英文（`en`），**强类型**约束，切换语言后已渲染界面**原地实时重译**，语言偏好持久化。

## 1. 概览

- 新增独立分包 `src/i18n/`，为**叶子包**（不依赖其它 `src/` 包），保证依赖无环。
- 文案键为扁平的「点分命名空间」字符串（`startup.mode.play`、`item.weapon_short_sword.name` …）。
- `MainLocale` 类型是唯一真相源：每个键的值要么是 `string`（普通文案），要么是 `(...args) => string`（需插值的文案）。
- 各语言表必须与 `MainLocale` **键完全一致**——缺少或多余的键在 `tsc` 阶段即报错（强类型）。
- `translate(key)` 的入参由键推导：字符串键直接传键名，参数键传 `{key, args}`，`args` 与函数签名逐参对齐。

## 2. 文件结构

```
src/i18n/
├── index.ts          # MainLocale 类型聚合 + 运行时（translate / getLocale / setLocale / onLocaleChange）
├── constants.ts      # LOCALES / DEFAULT_LOCALE / STORAGE_KEY / LOCALE_DISPLAY_NAMES / isLocale
├── zh_cn.ts          # 简体中文表（核心键 + 各域片段展开）
├── en.ts             # 英文表（核心键 + 各域片段展开）
├── dom.ts            # localizeText / localizeTitle / localizePlaceholder（设置值并登记自动重译）
├── index.test.ts     # 运行时单测
├── dom.test.ts       # DOM 助手单测
└── locales/          # 领域文案片段（每个域一个文件，type + zh + en）
    ├── entity.ts     # 实体面板 / 交互物 / 建筑 / 地形
    ├── catalog.ts    # 物品目录 / 装备槽位 / 武器名
    ├── character.ts  # 槽位 / 持握模式 / 攻击类别 / 护甲肢体名 / 角色面板
    ├── play.ts       # 游玩模式（HUD / 死亡 / 背包 / 箱子 / 地图）
    ├── showcase.ts   # 展示模式
    ├── bone_edit.ts  # 骨骼动画编辑器
    └── edit.ts       # 编辑模式（执行面板）
```

核心键（`common` / `startup` / `settings` / `camera` / `element` / `spawn` / `input` / `panel`）直接写在 `index.ts` 的 `CoreLocale`；其余按键命名空间拆到 `locales/*.ts`，由 `index.ts` 交叉组合、由 `zh_cn.ts` / `en.ts` 展开。这样**单文件不会无限膨胀**，且各域可独立维护。

## 3. API

```ts
import {translate, getLocale, setLocale, onLocaleChange} from '../../i18n/index.ts'
import {localizeText, localizeTitle, localizePlaceholder} from '../../i18n/dom.ts'

// 字符串键
translate('settings.title')

// 参数键（入参 args 与 locale 中函数签名一致）
translate({key: 'startup.imported', args: [file.name]})
translate({key: 'play.hud.charge_pct', args: [String(pct)]})

// 静态元素：设置值并登记，语言切换时自动重译
localizeText(el, 'startup.subtitle')
localizeTitle(btn, 'settings.title')
localizePlaceholder(input, 'skeleton.new_joint_name')
```

- `getLocale()` → 当前语言。
- `setLocale(locale)` → 持久化到 `localStorage`（`box_demo_language`）并通知订阅者。
- `onLocaleChange(fn)` → 订阅语言切换，返回取消订阅函数（用于 Canvas / Sprite 等需要主动重绘的场景）。
- 默认语言 `zh-cn`；读取失败 / 非法值安全回退，不抛错。

## 4. 新增一条文案

1. 在对应域文件（或 `index.ts` 的核心键区）的 **type** 中加入键：
   ```ts
   export type PlayLocale = {
       'play.foo': string
       'play.bar': (n: string) => string
   }
   ```
2. 在**同一文件的** `xxxZh` 与 `xxxEn` 中补齐两条（键必须一致）：
   ```ts
   'play.foo': '示例', 'play.bar': (n) => `数量 ${n}`,   // zh
   'play.foo': 'Example', 'play.bar': (n) => `Count ${n}`, // en
   ```
3. 调用处使用 `translate(...)` 或 `localizeText(...)`。`pnpm type-check` 即校验完整性。

## 5. 新增一种语言

1. `constants.ts` 的 `LOCALES` 增加标识；`isLocale` / `getLocales` / `LOCALE_DISPLAY_NAMES` 自动覆盖。
2. 复制 `zh_cn.ts` → `xx.ts`，实现 `MainLocale`。
3. `index.ts` 的 `LOCALE_TABLES` 加入该表。
4. 启动屏与设置菜单的语言选择器自动列出（`getLocales` 驱动）。

## 6. 实时重译与渲染约定

- **一次性构建的静态 UI**（启动屏、设置菜单、HUD 标题、生成类型面板、列表表头等）→ 用 `localizeText/localizeTitle/localizePlaceholder`，`setLocale` 时由 `dom.ts` 的 WeakRef 注册表统一刷新。
- **每帧 / 脏检查刷新的动态区**（HUD 数值、展示台状态、时间轴控件）→ 在其既有 `refresh()` 内调用 `translate(...)`，下一 tick 自动更新。
- **Canvas / Sprite 文本**（展示台名称标签、地图标记）→ 在 `onLocaleChange` 中重绘；字体栈同时含 CJK 与拉丁字体。
- **元素自带子控件时禁用 `localizeText`**：`localizeText` 走 `textContent`，语言切换刷新时会**清空子节点**（`select` / `input` 等会丢失）。此类「标签 + 控件」结构（如角色面板的武器 / 持握 / 势力下拉）必须用 `appendLocalizedText(parent, key)` 插入一个只承载文本的 `<span>`，再 `appendChild(控件)`。
- **计算型文案用 `localizeApply(el, apply)`**：`select` 的 `<option>`（含插值数值的武器 / 护甲名）、`optgroup.label`、属性预览等无法用单个键表达的内容，应登记计算函数——初始执行一次、语言切换时重算。禁止在构建期用 `translate(...)` 把结果冻结成常量（如模块级 `WEAPON_OPTIONS` 的 label）。
- **列表行等按需重算**：实体列表行文本（如角色的「武器名 + 倾向值 + 和平 / 战斗 / 原点策略」）经 `EntityPanelInfo.rowTextOf?: () => string` 提供，`element_list_panel` 每帧按需取值，避免冻结在构建语言。
- **原生控件文案不可本地化**：`<input type="file">` 的「选择文件 / 未选择文件」、`<select>` 的原生外观等由浏览器/系统提供，无法经 i18n 改写。需本地化时改为**自绘控件**（隐藏原生 input + 自定义按钮 + 文件名 span，如启动屏导入存档行）。
- 实体编辑面板随下次打开重译（面板为瞬时 UI，不持有跨语言状态）。

## 7. 数据名称与序列化字段

- **武器 / 护甲 / 肢体 / 物品名**：数据保留 `name` / `description`（中文），另以 `Record<id, StringLocaleKey>` 映射本地化名，经 `weaponDisplayName` / `armorPieceDisplayName` / `itemDisplayName` / `itemDisplayDescription` 取值；未知 id 回退数据值。**不改数据字段**，避免影响校验与既有测试。
- **骨架关节名**：`SkeletonDefinition` 的关节 `name` 会**序列化**（骨骼编辑器导出 / 导入、单测断言），因此不改数据；仅在人类性语境（角色面板锁定点下拉、列表行）经 `humanoidJointDisplayName(id, fallback)` 按 id 翻译，自定义关节回退原始名。
- **交互物实例名**：`name` 属于**稳定、非本地化的数据**——它既是玩家可改的显示名，也是 `modeInfo.play.teleports` 中传送点身份的键（`teleport:<name>`），因此**不随语言切换**（默认 `篝火` / `传送点`），避免存档身份随 locale 漂移。其**类型标签**（面板 / 列表行）仍走 `interactable.*` 键本地化；交互提示走 `interact.prompt.*`。
- **开发期错误 / `console.*`** 一律不翻译。
