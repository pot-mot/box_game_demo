# 远程攻击动作与握持

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。远程攻击均为单段 clip，不增加攻击阶段或播放系统。
> **弹丸在 `release` 阶段开始发射**（`ranged_executor`），因此动画的 t=0 就是举枪/拉弓/后引的起手位，释放帧的武器朝向必须与弹道一致。
> 整体节奏为原速的 **0.5 倍**（段时长与全部关键帧时间 ×2：长弓 0.4s / 弩 0.3s / 霰弹枪 0.6s / 法杖 0.6s / 魔杖 0.3s / 飞斧 0.5s / 手雷 0.8s / 燃烧瓶 0.8s / 飞镖 0.2s）。

## 逐动作重构（已验收）

| 段 id | 武器 | 动作（起手 → 释放 → 收招） |
|---|---|---|
| `longbow_shot` | 长弓 | 双手前举弓（箭向朝前）→ draw/aim 段保持瞄准并前送 → release 帧放箭后回戒备 |
| `crossbow_bolt` | 弩 | 双手托弩平举（枪口朝前）→ release 帧轻微后坐上抬 → 回戒备 |
| `shotgun_blast` | 霰弹枪 | 抵肩平举瞄准 → release 帧后坐上抬 → 回戒备 |
| `staff_orb` | 法杖 | 杖头前指、双手沿杖身错位 → release 帧前推送出 → 回戒备 |
| `magic_wand_homing` | 魔杖 | 单手前指（宝石朝目标）、左臂反向平衡 → release 帧甩腕 → 回戒备 |
| `throwing_axe_hurl` | 飞斧 | 举臂后引（斧头朝后上）→ release 帧抡臂前送、斧头朝前 → 回戒备 |
| `grenade_throw` | 手雷 | 举臂过顶后引 → release 帧前送抛出 → 回戒备 |
| `molotov_throw` | 燃烧瓶 | 举臂过顶后引（瓶口朝上）→ release 帧前送抛出 → 回戒备 |
| `throwing_dart_fling` | 飞镖 | 单 `release` 段：起手即甩出（手臂前伸、镖尖朝前）→ 回戒备 |

逐帧姿势修订见 `src/character/weapon/attack_pose_edits.ts`；模型握持坐标与左右手握距见 `src/entity/character/appearance/weapon_mesh.ts` 的生成器和握持数据。

## 武器模型握点

| 武器 | 主握点模型坐标 | 双手副握点 |
|---|---|---|
| 长弓 | 弦侧本地 `y = -size × 0.12` | 弓身中心，沿 `+Y` 回到弓把 |
| 弩 | 本地 `y = -size × 0.1, z = size × 0.09` | 前托方向 `size × 0.32`（左臂链长仅 0.36m，过长会脱柄） |
| 霰弹枪 | 本地 `y = -size × 0.1, z = size × 0.08` | 前托方向 `size × 0.26` |
| 法杖 | 杖身中点 `poleLen × 0.5` | 朝杖头方向 `poleLen × 0.3` |
| 魔杖 | 杖身 `len × 0.3` | 单手 |
| 飞斧 | 斧柄中心 | 单手 |
| 手雷 | 球心 | 单手 |
| 燃烧瓶 | 瓶身下段 `size × 0.2` | 单手 |
| 飞镖 | 杆身 `len × 0.25` | 单手 |

`createWeaponMesh` 将各握点经过武器固有旋转后平移到武器骨骼原点；枪械等偏轴握点也计入 `x/z`，命中箱与武器几何仍保留原始局部坐标。

## 验收

在骨骼动画模式逐把检查主握点是否落在右手、双手武器副握点是否落在左手；再在展示模式连续播放九个远程动作，确认投掷物握点、枪械握把和杖身位置不会随姿势滑移。
