# 待机

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。
> 状态：**已修正**（肘反向；握持由武器骨骼控制）。

## 状态

- 基础状态 `idle`，含两个变体：空手 `idle:n`、持械 `idle:w`（`weaponHeld` 后缀）。
- clip 由 `pose_fns.ts` 的 `idlePose` 按 60fps 烘焙（`clips/base_clips.ts`），时长 `2π / 1.8`，循环。

## 涉及关节

`rightArmShoulder`、`rightArmElbow`、`leftArmShoulder`、`leftArmElbow`、`headNeck`、`rightWeaponMount`、`leftWeaponMount`（持械握持角写在武器骨骼上）。

## 修正记录

- 肘由 `+0.85` 改为 `-0.85`：前臂向前折、肘尖朝后，符合人体。
- 握持屈角 `WEAPON_GRIP_FLEX = 1.7` 写在**武器骨骼**（`rightWeaponMount` / `leftWeaponMount`）上，使武器与前臂接近垂直（约 88°）；该值与攻击 clip 共用，保证攻击时武器不会与前臂共线，且双持时左右手可各自控制。
- 空手变体肘为 `-0.08`（几乎伸直），武器骨骼为 0。
