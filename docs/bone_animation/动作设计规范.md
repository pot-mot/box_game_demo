# 骨骼动画动作设计规范

> 适用范围：`entity/character/appearance/` 下的全部姿态与动画（基础状态 + 攻击段）。
> 本文件是 `docs/bone_animation/` 的**共用部分**；每个具体动作在此目录下单独建档，命名与结构见 §8。
> 相关文档：[骨骼动画系统](../bone_animation_system.md)、[攻击系统](../attack_system.md)、[展示模式](../showcase.md)。
> 状态：本文件描述**当前实现**（三种持握模式与双持已落地）。

## 1. 坐标系与身体朝向

- 角色模型原点在**脚底**，`+Y` 向上，`+Z` 为**面朝方向**。
    - 脸部纹理贴在 BoxGeometry 的 `+Z` 面（`render/box_parts.ts`）；
    - `character/weapon/melee_weapon.ts` 的 `detectBox` 注释明确「z 正向 = 朝向前方」；
    - `entity/character/physics/world.ts` 用 `atan2(dx, dz)` 求朝向。
- `group.rotation.y = 0` 时面朝世界 `+Z`；转身即绕 `+Y` 旋转。
- **左右命名注意**：代码中的 `rightArm*` / `rightLeg*` 位于 `+X` 侧。角色面朝 `+Z` 时，`+X` 实际是角色自身视角的**左侧**（与观察者/屏幕左右一致）。因此文档与提示词中一律用坐标表述（「`+X` 侧手臂（代码 `rightArm*`）」），避免「左/右」歧义。

提示词必须写明**身体朝向与观察角**，例如：

- 基准：面朝 `+Z`；
- 观察：从角色 `+X` 侧、略高于肩、朝 `-X` 方向看；
- 段内转身：无 / 方向 + 幅度（如「拧腰绕 `+Y` 转 +0.35 rad」）。

## 3. 旋转符号速查（关键）

以下规律基于「关节局部轴在静止时与角色对齐」。肢体默认沿 `-Y`（向下）延伸。

- 绕 `+X` 转 `θ`：肢体末端 z 位移 = `-sin(θ)` → **`θ > 0` 把末端甩向 `-Z`（身后），`θ < 0` 甩向 `+Z`（身前）**。
- 绕 `+Z` 转 `θ`：肢体末端 x 位移 = `+sin(θ)` → **`θ > 0` 把末端甩向 `+X`**。
- 绕 `+Y` 转 `θ`：沿竖直轴的自转/扭转。

| 关节 | `rx`（前后） | `ry`（自转/扭转） | `rz`（侧向） |
|---|---|---|---|
| 肩（手臂下垂） | `< 0` 前摆/上举；`> 0` 后摆 | 内旋 / 外旋（沿臂轴自转） | `> 0` 末端向 `+X`：`rightArm*` 外展、`leftArm*` 内收（镜像取反） |
| **肘** | **`< 0` 前折（自然，肘尖朝后）；`> 0` 反向（错误）** | 前臂自转 | 一般不用 |
| 手（`rightHandPivot` / `leftHandPivot`） | 手部俯仰（可动画，默认 0） | 手部自转 | 手部侧偏 |
| 腕 | 攻击/持械不再承载握持角（=0）；保留给手部动画 | — | 侧偏 |
| 武器骨骼（`rightWeaponMount` / `leftWeaponMount`） | `+WEAPON_GRIP_FLEX` 握持屈角（武器相对前臂垂直，见下方说明）；瞬态状态为 0 | 横斩刃面偏转（已烘焙进攻击关键帧） | 一般不用 |
| 髋 | `< 0` 大腿前迈；`> 0` 后摆 | 腿自转 | `> 0` 向 `+X` 开合 |
| **膝** | **`> 0` 小腿后折（自然）；`< 0` 反关节（错误）** | — | — |
| 脊柱 | `> 0` 前倾；`< 0` 后仰 | `> 0` 拧腰（朝向量转向 `+X`） | `> 0` 向 `-X` 侧倾 |
| 头/颈 | `> 0` 低头；`< 0` 抬头 | 左右转头 | `> 0` 向 `-X` 侧偏 |

> **肘与膝方向相反**：这是本系统最容易出错的地方。持械戒备、受击硬直与攻击段的肘现已统一为负值（`WEAPON_READY_ELBOW = -0.85`、`FLINCH_ELBOW = -1.2`、攻击 `elbowBend`、左臂 `ATTACK_LEFT_ELBOW_BEND` / `TWO_HAND_GRIP.elbow` 均为负）。
> **武器骨骼控制武器朝向**：武器模型绑定在**独立的左右手武器骨骼**（`rightWeaponMount` / `leftWeaponMount`）下——层级为 `腕 → 武器骨骼 → 武器模型`；武器的固有握持（握把对齐模型原点 + 固有前倾角）在建模时由 `createWeaponMesh` 直接烘焙进模型（`weapon_mesh.ts` 的 `WEAPON_MESH_GRIPS`），**运行时不再有任何外部偏移/倾斜节点或动作常量**。握持屈角施加在**武器骨骼**上（`WEAPON_GRIP_FLEX = 1.7 rad`，武器相对前臂接近垂直）；**待机 / 行走（持械）与攻击收招帧保持该屈角**；攻击的起手/打击帧允许（且应当）用武器骨骼把刃面摆进打击平面（挥砍时刃尖朝打击方向、枪械/弓弩枪口与箭向朝目标），否则会出现「举械不砍 / 枪口朝天」。腕关节只做小幅甩腕，不承担主朝向。
> 武器与前臂夹角 = 180° − |`WEAPON_GRIP_FLEX` + 该武器固有前倾|（≈83°~90°）。
> 瞬态状态（跳跃 / 下落 / 死亡 / 受击）不施加握持角，武器随臂自然摆动。

## 4. 阶段（phase）与相位（phase offset）

两个中文都叫「phase」的概念需要区分：

- **阶段（attack phase）**：结构性的时间区段，来自 `character/combat/attack_phases.ts` 的 `ATTACK_PHASES = ['windup', 'strike', 'recovery', 'spin', 'draw', 'aim', 'release']`。它决定「这个段由哪几块组成、各占多久」（`durationRatio` 分摊动作时间，`recovery` 独立取段的恢复时间）。
- **相位（phase offset）**：同一段内**左手相对右手的时间/进度偏移**（取值 0~1）。它不改阶段结构与时长，只让副手早/晚到达峰值。

> **现状（已烘焙）**：攻击动画是显式骨骼关键帧数据（`character/weapon/attack_clip_data.ts`），**相位已烘焙进左臂关键帧**（双斧即左右交替），不再有 `leftArm.phaseOffset` 运行时常量。下面仅作为相位语义的解释；调整交替节奏直接改对应段的关键帧。

相位错开必须配合**按槽的命中事件**（见 §7），否则共享命中窗口会让后挥的一手落空。

## 5. 动作来源与改动位置

| 想改什么 | 改哪里 |
|---|---|
| 基础状态（待机/行走/跳跃/下落/死亡/冲刺/受击）姿态 | `src/entity/character/appearance/pose_fns.ts`（`BASE_POSE_SAMPLERS` / `BASE_CLIP_META`）；基础 clip 烘焙在 `clips/base_clips.ts`。**死亡保持直立**：倒地方向由 `states/dying.ts` 依据最后受击冲击方向决定，`world.ts` 合成根旋转（骨骼编辑器预览即直立） |
| 攻击段的**具体骨骼动作**（各关节旋转/武器朝向/双手幅度/弓步/头/刃面） | 基础轨道 `src/character/weapon/attack_clip_data.ts` + 逐段关键姿势修订 `attack_pose_edits.ts`；只修现有关键时刻，不改变阶段/时长。**三段式约定**：t=0 起手/蓄力、中帧（= 动作段结束）= 打击完成、末帧 = 持械戒备（肩 `-0.45` / 肘 `-0.85` / 挂点 `1.7`，与 idle 一致） |
| 近战命中窗口（hitbox_on/off 时间） | `attack_clip_data.ts` 事件轨：on ≈ 0.5×动作时间、off ≈ 0.95×动作时间（对齐打击帧）；双持按 `params.weapon` 分主/副手单独设窗 |
| 攻击段时长 / 恢复 / 阶段时序 / 伤害倍率 / 连段拓扑 | `src/character/weapon/melee_attacks.ts`、`melee_special_moves.ts`、`ranged_attacks.ts` |
| 持握模式（单持/双手共持/双持） | 武器数据 `twoHanded` / `offhandMesh`（`melee_weapon.ts`、`ranged_weapon.ts`） |
| 双手副握点 / 武器骨骼握持屈角 | `weapon_mesh.ts` 的每武器 `supportGripOffset` / `constants.ts` 的 `WEAPON_GRIP_FLEX` |
| 武器模型握持中心 / 网格几何 | `src/entity/character/appearance/weapon_mesh.ts`（各 `gen*` 的 grip 点、`WEAPON_MESH_GRIPS`） |
| 预览整链衔接 | 展示模式 `modes/showcase/` |
| 逐 clip 精修、拖关节、看轨道 | 骨骼动画模式 `modes/bone_edit/` |

> 攻击动画基础关键帧与逐段姿势修订由 `getAttackClipById` 合并后**惰性解析缓存**（进程内）；编辑 `attack_clip_data.ts` 或 `attack_pose_edits.ts` 后需重启 `pnpm dev`。基础状态 clip 仍由 `pose_fns.ts` 公式按 `CLIP_SAMPLE_FPS` 烘焙。

## 7. 双持与左右手参数（方案 a，已实现）

### 7.1 三种持握模式

由「武器是否提供 `offhandMesh`」+「段的 `twoHanded`」推导：

| 模式 | 判据 | 左手行为 |
|---|---|---|
| 单持 | 无 `offhandMesh`，段 `twoHanded = false` | 反摆平衡（不与武器耦合） |
| 双手共持 | 无 `offhandMesh`，段 `twoHanded = true` | 左手链 IK 贴合主手武器轴（`two_handed_ik.ts`） |
| 双持 | 有 `offhandMesh` | 左手独立握持自身武器（不启用共享 IK） |

武器数据形态（单持/双手 = `offhandMesh` 为 `undefined`）：

```ts
interface WeaponConfig {
    readonly mesh: WeaponMeshConfig            // 主手（右手）
    readonly offhandMesh?: WeaponMeshConfig    // 副手（左手），undefined = 单/双手
    // ...
}
```

双持武器（当前仅双斧）的副手网格用 `mirror: true` 让斧刃开向 `-X`（两把刃口均朝外）。

### 7.2 每段独立左右手动作

攻击动画以**显式骨骼关键帧**表达：基础轨道在 `character/weapon/attack_clip_data.ts`，本轮逐段局部姿势修订在 `attack_pose_edits.ts`，双持左右交替时间保持在各段原有关键帧。**不再有** `ArmAnimConfig` / `leftArm` / `phaseOffset` / `phase.animConfig` 等参数；修订只覆盖已有时间点上的关节姿势，不生成额外阶段或动作逻辑。

### 7.3 武器骨骼与命中窗口

- `rightWeaponMount` / `leftWeaponMount` **已纳入可动画关节**（静止为单位变换）：可在不改手部网格的前提下微调武器朝向（例如补偿肘角修正后武器发生的前后倾）。
- **武器模型自带固有握持**：握把对齐模型原点、固有前倾角已烘焙进模型（`createWeaponMesh`），武器直接挂在武器骨骼下，clip 写武器骨骼即为最终朝向。
- **按武器分组的命中事件**：攻击 clip 的 `hitbox_on` / `hitbox_off` 带 `params.weapon: 'main' | 'offhand'`；双持时主/副手各一对，副手窗口落在烘焙后的副手动作段内。近战执行器 `setHitWindow(active, weapon?)` 按槽独立开关（缺省 = 两手同时），实现「左手在右手恢复期挥出并照常结算伤害」。状态切换的合成关闭事件不带 `weapon`，会同时关闭两手。

## 8. 逐动作文档与命名约定

- 目录：`docs/bone_animation/`。

## 9. 陷阱

- **肘符号**：肘 `rx` 必须 `< 0`（前折）；膝 `rx` 必须 `> 0`（后折）。二者方向相反，禁止照抄。
- **`right*` 在 `+X` 侧**：是镜像命名，勿按角色解剖左右理解。
- **武器骨骼是唯一朝向来源**：武器的偏移/倾斜/旋转全部由武器骨骼（clip 轨道）与模型固有握持（烘焙）决定，禁止再引入运行时外部握持常量或中间挂点节点。
- **主、副握点**：`createWeaponMesh` 按每把模型的握点坐标 `(x,y,z)` 与固有旋转，将主握点烘焙到模型根原点；`supportGripOffset` 为该武器左手副握点相对主握点沿本地 `+Y` 的有符号距离。双手 IK 使用每把武器的副握距，不能把所有武器都设为零间距，也不能仅以几何包围盒中心推断握点。
- **三段式关键帧**：t=0 起手（上举/后引/瞄准）、中帧 = 打击完成姿态、末帧 = 持械戒备（肩 `-0.45` / 肘 `-0.85` / 挂点 `1.7`）。若把 t=0/末帧写成垂臂全零，会与 idle 戒备位发生两次跳变，且「打击帧」容易变成举械不动。
- **挥砍靠武器骨骼摆平面**：`WEAPON_GRIP_FLEX = 1.7`（武器⊥前臂）只是戒备/待机握法；下劈、横斩、突刺的打击帧必须用 `rightWeaponMount`（必要时 `rightWristPivot`）把刃尖转向打击方向（下劈约 `3.0~3.4`、突刺沿前臂约 `3.0`），否则刃尖永远朝上。
- **双手 IK 可达性（左肩→副握点 ≤ ~0.34m）**：左臂链长仅 0.36m；双手段每个关键帧（含插值路径）都要让副握点落进臂展，否则 `solveTwoHeldGrip` 会截断、左手脱柄悬空。手段：双手收向身体中线（x ≈ 0~0.1）、躯干前倾（`spine.rx` 0.25~0.4，肩随之前移）、避免把武器伸到最远。副握点位置 = 武器模型握点 + `weaponSupportGripOffset` 沿武器本地 `+Y`（不同武器握距不同，长枪/巨剑很短、弩/霰弹枪较长）。
- **IK 只在骨架空间求解**：目标与臂展都按未缩放的骨架空间计算；模型根带缩放时（展示模式 `ACTOR_SCALE = 1.3`）必须把武器世界目标经 `rootObject`（`model.group`）换算回骨架空间，否则目标与臂展分属两个空间、左手脱离武器。
- **左肘极向约束**：CCD 会把左肘收敛成「反折朝上/后」（远程武器、恢复段尤其明显）。`two_handed_ik.ts` 在 `solveCcd` 后绕「肩→手」轴旋转整条手臂，把左肘摆到「下 + 角色外侧」（手在轴上不受影响），保证不生反关节。
- **肘符号**：关键帧中肘 `rx` 一律为**负值**（前折）；新增/调整动作时不得写成正值。
- **命中窗口按武器槽分组**：双持主/副手窗口独立（见 §7.3）；近战窗口对齐打击帧（on ≈ 0.5×动作时间、off ≈ 0.95×动作时间）。
- **远程弹丸在 `release` 阶段开始发射**（`ranged_executor`）：动画 t=0 起手就要指向目标（弓/弩/枪械的枪口、箭向朝前；投掷类后引起手），释放帧的姿势与弹道方向一致，否则弹丸会从垂臂/朝天姿态飞出。
- **状态切换有 0.15s 快照混合**（`STATE_BLEND_DURATION`）：关节角突跳会被平滑，调参时不要把过渡帧算作目标姿态。
- **攻击动画数据即真相源**：基础轨道在 `attack_clip_data.ts`，逐段关键姿势修订在 `attack_pose_edits.ts`；改动后重启 `pnpm dev` 生效（解析结果进程内缓存），修订的关节与时间必须存在于基础 clip。
