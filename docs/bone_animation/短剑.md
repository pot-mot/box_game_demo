# 短剑

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。
> 状态：**已修正**（攻击武器相对前臂保持垂直，与待机一致）。

## 武器配置

- id `short_sword`，中文名「短剑」，`type: melee`，单手（`twoHanded: false`）。
- 网格：`{id: 'sword', bladeLen: 0.3}`；无副手网格。

## 攻击段（4）

| 段 id | 动作 |
|---|---|
| `short_sword_light_1` | 上→下竖劈 |
| `short_sword_light_2` | 探身直刺 |
| `short_sword_heavy_1` | 横向挥砍 |
| `short_sword_heavy_2` | 斜向挥砍 |

## 握持与修正

- 待机/行走（持械）与攻击关键帧共用 `WEAPON_GRIP_FLEX = 1.7`，**写在武器骨骼 `rightWeaponMount`**（腕关节不承担握持角），武器相对前臂接近垂直（约 88°）。
- **修正前**：攻击把握持角写在腕关节且数值很小，武器与前臂共线（观感「武器贴着手臂」）；现由武器骨骼统一控制，攻击全程与待机一致。
- 动作形态（含横斩刃面偏转）是段 id 的显式骨骼关键帧（`attack_clip_data.ts`）。

## 关联代码

- 段定义：`src/character/weapon/melee_attacks.ts`（模板）+ `melee_weapon.ts`（预设）
- 动画关键帧：`src/character/weapon/attack_clip_data.ts`（`short_sword_light_1` 等）
- 武器骨骼与握持：`src/entity/character/appearance/constants.ts`（`WEAPON_GRIP_FLEX`）、`pose_fns.ts`

## 验收

展示模式或骨骼动画模式播放短剑 4 段：武器相对前臂保持与待机相同的近垂直角度，不再与前臂共线。

## 本轮动作重构（三段式，已验收）

关键帧按统一三段式重写：**t=0 起手/蓄力 → 中帧 = 打击完成 → 末帧 = 持械戒备**（肩 `-0.45` / 肘 `-0.85` / 挂点 `1.7`，与 idle 衔接无跳变）。挥砍平面由武器骨骼 `rightWeaponMount` 承担（打击帧约 `3.0`，让刃尖指向打击方向），腕关节只做小幅甩腕。

| 段 | 动作（起手 → 打击完成） |
|---|---|
| `short_sword_light_1` | 右肩上方竖举 → 前下劈至腰前（刃尖朝前下） |
| `short_sword_light_2` | 撤手蓄力（剑在胯侧、刃尖朝前）→ 前刺，躯干前倾、左臂后摆平衡 |
| `short_sword_heavy_1` | 右上方横举 → 横扫过身体中线，躯干反向拧转 |
| `short_sword_heavy_2` | 右上举 → 斜劈至左前下，落点与横斩区分 |

整体节奏为原速的 0.75 倍（轻段动作 0.267s + 恢复 0.266s、重段 0.4s + 0.267s），命中窗口同步对齐打击帧（轻段 on 0.133s / off 0.253s；重段 on 0.2s / off 0.38s）。具体关节关键帧见 `src/character/weapon/attack_pose_edits.ts`；短剑握把在 `weapon_mesh.ts` 中以本地柄中心对齐主手挂点。
