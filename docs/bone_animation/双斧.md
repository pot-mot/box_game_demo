# 双斧

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。
> 状态：**已实现**（首把双持武器）。

## 武器配置

- id `dual_axe`，中文名「双斧」，`type: melee`（`melee_weapon.ts`）。
- 持握模式：**双持**（`twoHanded: false` + `offhandMesh` 存在）。
- 主手网格 `mesh: {id: 'dual_axe', bladeSize: 0.3, ...}`；副手 `offhandMesh: {id: 'dual_axe', ...}`（与主手同网格）。
- 网格 `genDualAxe` 生成**单刃斧**（柄 + 一片斧刃，刃接柄顶）；刃面立于本地 Y-Z 平面（宽沿本地 `Z`、薄沿本地 `X`）。该几何关于本地 `X` 轴对称，左手武器即右手武器关于角色矢状面的镜像，故副手不再做额外翻转。

## 攻击动作

- 4 个段（轻 1 / 轻 2 / 重 1 / 重 2）的左右交替（相位错开半程 → 右手前半程挥出、左手在其恢复期挥出）已**烘焙进各段的关键帧**（`attack_clip_data.ts`），不再有 `mirrorLeftArmPhaseOffset` / `leftArm` / `phaseOffset` 参数。
- 命中事件按槽分组：主手一对（`params.weapon: 'main'`），副手一对（`'offhand'`）；近战执行器分别开关左右命中箱，**两只手都会结算伤害**。

## 本轮动作重构（三段式，已验收）

每段三关键帧：**t=0 双手同时上举（起手）→ 主手在中帧下劈（副手保持蓄势）→ 副手在后一关键帧下劈（主手收招）→ 末帧回戒备**。两把斧各自用武器骨骼 `rightWeaponMount` / `leftWeaponMount` 把斧刃摆进下劈方向（打击帧约 `3.0`，收招回 `1.7`）；0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s），命中窗口按槽分组：轻段主手 0.133/0.253s、副手 0.293/0.4s；重段主手 0.2/0.38s、副手 0.427/0.533s。

| 段 | 动作（主手/副手） |
|---|---|
| `dual_axe_light_1` | 双手上举 → 右手前下劈 → 左手中线侧前下劈 |
| `dual_axe_light_2` | 双手上举 → 右手外斜下劈 → 左手外斜下劈（与第一段落点相反） |
| `dual_axe_heavy_1` | 双手高位上举 → 右手重劈 → 左手重劈（幅度更大、躯干拧转更多） |
| `dual_axe_heavy_2` | 同重 1 的交替结构，两侧落点与末姿势区分 |

修订关键帧见 `src/character/weapon/attack_pose_edits.ts`；双斧主、副武器各自以柄中心对齐左右手挂点，继续使用分槽命中事件。
