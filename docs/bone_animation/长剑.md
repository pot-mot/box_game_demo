# 长剑

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。
> 状态：**已修正**（攻击武器相对前臂保持垂直，与待机一致）。

## 武器配置

- id `long_sword`，中文名「长剑」，`type: melee`，单手（`twoHanded: false`）。
- 网格：`{id: 'sword', bladeLen: 0.5}`；无副手网格。默认武器（`DEFAULT_WEAPON_ID`）。

## 攻击段（4）

| 段 id | 动作 |
|---|---|
| `long_sword_light_1` | 上→下竖劈 |
| `long_sword_light_2` | 探身直刺 |
| `long_sword_heavy_1` | 横向挥砍 |
| `long_sword_heavy_2` | 斜向挥砍 |

## 握持与修正

- 与短剑同：待机/行走（持械）与攻击关键帧共用 `WEAPON_GRIP_FLEX = 1.7`，**写在武器骨骼 `rightWeaponMount`**，武器相对前臂接近垂直；修正前把握持角写在腕关节且数值过小，导致武器与前臂共线，现与待机一致。
- 挥砍幅度与方向直接体现在各段的关键帧数据中。

## 验收

展示模式或骨骼动画模式播放长剑 4 段：武器相对前臂保持与待机相同的近垂直角度。

## 本轮动作重构（三段式，已验收）

与短剑同型、幅度更大：**t=0 起手/蓄力 → 中帧 = 打击完成 → 末帧 = 持械戒备**；挥砍平面由武器骨骼承担（打击帧挂点约 `3.0`，收招回 `1.7`）；0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s），命中窗口对齐打击帧（轻段 0.133s / 0.253s；重段 0.2s / 0.38s）。

| 段 | 动作（起手 → 打击完成） |
|---|---|
| `long_sword_light_1` | 头顶后方竖举 → 前下劈，刃尖落到胸腹前 |
| `long_sword_light_2` | 撤手蓄力 → 前刺（躯干前倾、左臂后摆） |
| `long_sword_heavy_1` | 右上方横举 → 横扫过中线 |
| `long_sword_heavy_2` | 右上举 → 斜劈至左前下 |

具体关键姿势见 `src/character/weapon/attack_pose_edits.ts`。双手共持时副手按长剑握柄长度单独定位，不与主手重叠；`two_handed` 模式的段姿势共用该套关键帧，左手经 IK 贴合副握点。
