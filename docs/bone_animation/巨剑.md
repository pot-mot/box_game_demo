## 双手共持修正记录

> 以下第一轮修正记录用于解释旧问题；当前握点已升级为模型几何中心校正 + 每武器独立副握距，见文末。

**问题**：攻击时左手没有吸附在武器上，而是抓向刃尖、远离主手（观感「甩出去」）。

**原因**：
1. 副握点从**武器模型原点**沿 +Y 偏移计算，而握把中心在原点下方（`gripY < 0`），原 `TWO_HAND_GRIP_OFFSET = 0.45` 实际落在刃部；
2. 主手臂展约 0.36m，主手肘近乎伸直时握把离左肩约 0.46m，超出臂展，左手 IK 永远够不到。

**修正**：
1. 副握点改为「握把处」：offset = `weaponGripY + TWO_HAND_GRIP_OFFSET`（`= -0.11`，即主手握把处）；
2. 各段关键帧把主手肘明显屈起（原 `elbowBendScale = 5` 的效果已烘焙进 `attack_clip_data.ts`），武器落入左手臂展内；
3. 左肘极向约束（`two_handed_ik.ts`）：CCD 后绕「肩→手」轴把左肘摆到「下 + 外侧」，消除反关节；
4. 回归测试 `system.test.ts` 断言全部双手武器（含远程）：左手武器骨骼贴近握把且左肘朝下。

## 本轮动作重构（三段式，已验收）

**t=0 起手/蓄力 → 中帧 = 打击完成 → 末帧 = 持械戒备**；挥砍平面由武器骨骼承担，0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s），命中窗口对齐打击帧（轻段 on 0.133s / off 0.253s；重段 on 0.2s / off 0.38s）。双手姿势的关键约束：**每个关键帧（含插值路径）左肩→副握点 ≤ 0.34m**，因此双手收向身体中线、躯干前倾带出打击距离（`system.test.ts` 逐帧扫描 0.18m 阈值锁定）。

| 段 | 动作（起手 → 打击完成） |
|---|---|
| `heavy_sword_light_1` | 头顶竖举（双手近额前）→ 前下劈，剑尖落到腹前 |
| `heavy_sword_light_2` | 撤手蓄力 → 双手前刺（躯干前倾） |
| `heavy_sword_light_3` | 低位后引（剑尖朝前下）→ 上挑斜斩至右上 |
| `heavy_sword_heavy_1` | 右肩上方横举 → 横扫过中线 |
| `heavy_sword_heavy_2` | 高位竖举 → 斜劈至左前下 |

姿势关键帧见 `src/character/weapon/attack_pose_edits.ts`。当前巨剑模型主握点在握柄中心，左手副握点沿武器本地 `+Y` 与主手错开 `0.065m`；`TWO_HAND_GRIP_OFFSET` 仅为额外微调，不再承担把主、副手从同一点分开的职责。
