## 双手共持修正

**问题**：攻击时左手没有吸附在武器上，而是抓向刃尖、远离主手（观感「甩出去」）。

**原因**：
1. 副握点从**武器模型原点**沿 +Y 偏移计算，而握把中心在原点下方（`gripY < 0`），原 `TWO_HAND_GRIP_OFFSET = 0.45` 实际落在刃部；
2. 主手臂展约 0.36m，主手肘近乎伸直时握把离左肩约 0.46m，超出臂展，左手 IK 永远够不到。

**修正**：
1. 副握点改为「握把处」：offset = `weaponGripY + TWO_HAND_GRIP_OFFSET`（`= -0.11`，即主手握把处）；
2. 各段关键帧把主手肘明显屈起（原 `elbowBendScale = 5` 的效果已烘焙进 `attack_clip_data.ts`），武器落入左手臂展内；
3. 左肘极向约束（`two_handed_ik.ts`）：CCD 后绕「肩→手」轴把左肘摆到「下 + 外侧」，消除反关节；
4. 回归测试 `system.test.ts` 断言全部双手武器（含远程）：左手武器骨骼贴近握把且左肘朝下。
