# 战锤

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。
> 状态：**已修正**（锤头对齐柄顶）。

## 武器配置

- id `war_hammer`，中文名「战锤」，`type: melee`（`melee_weapon.ts`）。
- 持握模式：三模式（默认单持；**双手共持为主设计形态**），左手链 IK 贴合主手武器轴。三模式连段总表见 [`持握模式动作.md`](持握模式动作.md)。
- 网格：`headSize = 0.35`、`color`、`gripColor`。

## 网格生成（`genWarHammer`）

```
hsz  = headSize = 0.35
gLen = hsz * 1.5 = 0.525
柄：cyl(r=0.04, h=gLen)，中心 y = -hsz*0.2 - gLen/2 = -0.3325
     → 柄范围 y ∈ [-0.595, -0.07]，柄顶 = -0.07
锤头：box(0.245 × 0.175 × 0.245)，中心 y = hsz*0.05 = 0.0175
     → 锤头范围 y ∈ [-0.07, 0.105]，锤头底 = -0.07
```

## 问题与修正

原实现柄顶 `-0.07` 与锤头底 `0.28` 之间空 `0.35`，柄与锤头**断开**。

修正：锤头底对齐柄顶，`headY = handleTop + headH/2 = -hsz·0.2 + hsz·0.25 = hsz·0.05`；命中箱中心 y 与刀尖采样点同步为锤头中心/顶端。

## 本轮动作重构（三段式，已验收）

**t=0 起手/蓄力 → 中帧 = 打击完成 → 末帧 = 持械戒备**；锤头朝向由武器骨骼承担（打击帧挂点约 `3.35`，锤头指向打击方向），0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s），命中窗口轻段 on 0.133s / off 0.253s、重段 on 0.2s / off 0.38s。锤的副握点距主握较远（约 0.25m），双手必须收在身体中线附近、避免把锤伸到臂展外（`system.test.ts` 上限 0.18m 的副握残差）。

| 段 | 动作（起手 → 打击完成） |
|---|---|
| `war_hammer_two_handed_light_1` | 头顶竖举 → 前下敲，锤头落到胸腹前 |
| `war_hammer_two_handed_light_2` | 右上方举 → 另一侧斜向敲击 |
| `war_hammer_two_handed_heavy_1` | 右侧横举 → 横向重摆过中线 |
| `war_hammer_two_handed_heavy_2` | 高位竖举 → 向下重砸（收在胸前方向，受臂展约束） |

关键姿势见 `src/character/weapon/attack_pose_edits.ts`。模型握把中心由柄段中心点对齐右手；左手副握点在 `weapon_mesh.ts` 中按柄身单独声明。

## 三持握模式（逐模式连段）

| 模式 | 段前缀 | 动作轨迹 |
|---|---|---|
| 单持（默认） | `war_hammer_one_handed_*` | 单手前下敲 / 单手斜敲 / 单手横摆 / 单手重砸（**外侧敲击**：肩 `rz` 为正、手臂在身体外侧；左臂反向平衡） |
| 双手共持 | `war_hammer_two_handed_*` | 上表四段 |
| 双持 | `war_hammer_dual_wield_*` | 右手外侧敲击四段；左手滞后 0.133s 镜像（外侧摆幅）。**重击为过顶大重砸 / 斜重砸**：起手高举过顶、打击帧手臂下压 + 武器骨骼 3.45~3.48（锤头砸到底）、躯干前倾 0.42 + 重心下沉（`spine.y −0.09`）+ 深弓步，随挥帧保持低位（3.4）再收招 |

单持/双持段由模板族精修为战锤专属幅度（per-weapon patch），双手段为原有手工链；全部段可在骨骼动画编辑器按「战锤 · 模式 · 段名」逐段调姿势。
