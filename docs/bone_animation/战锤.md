# 战锤

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。
> 状态：**已修正**（锤头对齐柄顶）。

## 武器配置

- id `war_hammer`，中文名「战锤」，`type: melee`（`melee_weapon.ts`）。
- 持握模式：**双手共持**（`twoHanded: true`），左手链 IK 贴合主手武器轴。
- 网格：`headSize = 0.35`、`color`、`gripColor`。

## 网格生成（`genWarHammer`）

```
hsz  = headSize = 0.35
gLen = hsz * 1.5 = 0.525
柄：cyl(r=0.04, h=gLen)，中心 y = -hsz*0.2 - gLen/2 = -0.3325
     → 柄范围 y ∈ [-0.595, -0.07]，柄顶 = -0.07
锤头：box(0.245 × 0.175 × 0.245)，中心 y = hsz*0.05 = 0.0175
     → 锤头范围 y ∈ [-0.07, 0.105]，锤头底 = -0.07
```

## 问题与修正

原实现柄顶 `-0.07` 与锤头底 `0.28` 之间空 `0.35`，柄与锤头**断开**。

修正：锤头底对齐柄顶，`headY = handleTop + headH/2 = -hsz·0.2 + hsz·0.25 = hsz·0.05`；命中箱中心 y 与刀尖采样点同步为锤头中心/顶端。

骨骼动画模式手动装备战锤：柄与锤头连接为一体，命中箱环绕锤头。

## 本轮动作重构（三段式，已验收）

**t=0 起手/蓄力 → 中帧 = 打击完成 → 末帧 = 持械戒备**；锤头朝向由武器骨骼承担（打击帧挂点约 `3.35`，锤头指向打击方向），0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s），命中窗口轻段 on 0.133s / off 0.253s、重段 on 0.2s / off 0.38s。锤的副握点距主握较远（约 0.25m），双手必须收在身体中线附近、避免把锤伸到臂展外（`system.test.ts` 上限 0.18m 的副握残差）。

| 段 | 动作（起手 → 打击完成） |
|---|---|
| `war_hammer_light_1` | 头顶竖举 → 前下敲，锤头落到胸腹前 |
| `war_hammer_light_2` | 右上方举 → 另一侧斜向敲击 |
| `war_hammer_heavy_1` | 右侧横举 → 横向重摆过中线 |
| `war_hammer_heavy_2` | 高位竖举 → 向下重砸（收在胸前方向，受臂展约束） |

关键姿势见 `src/character/weapon/attack_pose_edits.ts`。模型握把中心由柄段中心点对齐右手；左手副握点在 `weapon_mesh.ts` 中按柄身单独声明。
