# 近战三持握模式动作总表

> 本文件汇总全部近战武器类在三种持握模式下的连段（段 id / 动作轨迹），是逐武器文档（`短剑.md` / `长剑.md` / `巨剑.md` / `长枪.md` / `双斧.md` / `战锤.md`）的模式索引。
> 共用规范见 [`动作设计规范.md`](动作设计规范.md)；系统设计见 [`../melee_hold_modes.md`](../melee_hold_modes.md)。

## 段 id 约定

`{classId}_{holdMode}_{模板键}`，模板键 = `light_1` / `light_2` / `light_3` / `heavy_1` / `heavy_2`（长枪双手另有变体段 `spear_two_handed_charge_thrust`）。

## 模式语义

| 模式 | 副手 | 左手动作 | 命中窗口 |
|---|---|---|---|
| `one_handed` 单持（默认） | 副手武器握在左手（任意类别） | 反摆平衡（幅度随武器重量分级） | 仅 `main` |
| `two_handed` 双手共持 | 副手武器挂背 | 左手链 IK 贴合主手武器副握点 | 仅 `main` |
| `dual_wield` 双持（需副手同类近战） | 左手握副手武器 | 左右手交替（副手滞后 0.133s，逐武器握向） | `main` + `offhand` 分槽 |

## 各武器三模式动作轨迹

| 武器类 | 单持 | 双手共持 | 双持 |
|---|---|---|---|
| `short_sword` 短剑 | 竖劈 / 前刺 / 横扫 / 斜劈（原有手工链） | 双手竖劈 / 双手前刺 / 双手横扫 / 双手斜劈（幅度收拢、双手贴近） | 右手同单持四段；左手滞后半程镜像（外摆起手 → 下劈 / 横扫 / 斜劈） |
| `long_sword` 长剑 | 竖劈 / 前刺 / 横扫 / 斜劈（原有手工链） | **前刺** / 上挑 / 横扫 / 斜劈（长刃双手链以刺为首段） | 右手同单持四段；左手滞后镜像（握向 2.8→3.0） |
| `heavy_sword` 巨剑 | 单手重劈 / 单手前刺 / 单手横扫 / 单手斜劈（**外侧挥砍**：肩外展，手臂不横穿身体） | 竖劈 / 前刺 / 上挑（轻 3）/ 横扫 / 斜劈（原有手工链） | 右手外侧重劈 / 前刺 / 横扫 / 斜劈；左手滞后镜像（外侧摆幅，肘更屈） |
| `spear` 长枪 | **侧身枪架**：根关节侧转 + 下肢错步，单手平刺 / 单手侧刺 / 单手横扫 / 单手斜砸 | **侧身枪架**：平刺 / 侧刺 / 横扫 / 下砸 | **侧身枪架**：右手枪刺 / 侧刺 / 横扫 / 下砸；左手滞后镜像 |
| `dual_axe` 双斧 | 单手斧劈 / 外斜劈 / 重劈 / 斜重劈 | 双手斧劈 / 双手斜劈 / 横扫 / 重劈（斧刃朝下、握把双握） | 交替下劈（原有手工链，左右相位错开半程） |
| `war_hammer` 战锤 | 单手前下敲 / 单手斜敲 / 单手横摆 / 单手重砸（**外侧敲击**） | 前下敲 / 斜敲 / 横摆 / 重砸（原有手工链） | 右手外侧敲击四段；左手滞后镜像（外侧摆幅）。重击为过顶大重砸：打击帧手臂下压 + 武器骨骼 3.45~3.48 + 躯干前倾 + 重心下沉 + 深弓步，随挥保持低位 |

### 穿模修正约定

- **外侧挥砍（巨剑单持/双持、战锤单持/双持）**：肩关节 `rz` 取正（右臂在身体外侧、左臂镜像在另一侧），起手/打击帧手臂不横穿躯干；重兵器的握向由武器骨骼单独承担。
- **侧身枪架（长枪三模式）**：`root` 关节绕 `+Y` 侧转（单持 0.38 / 双手 0.5 / 双持 0.28 rad），`spine` 反向拧转抵消（净胸口偏角约 0.1 rad），下肢错步（前腿 `rx < 0`、后腿支撑）；收招帧根/下肢回零与 idle 衔接。侧身让横抱枪杆的手臂获得空间，消除手臂-躯干穿模。

## 动画来源与精修方式

- 三模式段数据均在 `attack_clip_data.ts`（基础稀疏关键帧）+ `attack_pose_edits.ts`（逐段姿势修订）中显式定义，共 83 条攻击段（近战 74 + 远程 9）。
- 每条链按武器选择动作原型（下劈 / 前刺 / 上挑 / 横扫 / 斜劈 / 枪刺 / 锤砸 / 斧劈），并以 per-weapon patch 覆盖右臂幅度、武器骨骼朝向（挥砍平面）与躯干拧转；左手按模式分别生成（平衡 / 副手支撑 / 滞后镜像 + 逐武器握向）。
- **双手共持**：右臂保持在左臂臂展内（左肩→副握点 ≤ 0.34m），打击帧用武器骨骼把刃/枪口/锤头转向打击方向；副手武器挂背不影响 IK。`appearance/system.test.ts` 对全部双手链逐帧锁定残差 < 0.18m、左肘朝下。
- **双持**：主/副手各一对命中事件（`params.weapon: 'main' | 'offhand'`），副手窗口在主手窗口之后；副手命中按副手武器数值结算；左手武器朝向由 `leftWeaponMount` 逐段关键帧承担。
- 各模式在展示模式按排展示（单持 / 双手 / 双持三排），可在骨骼动画编辑器中按「武器 · 模式 · 段名」选择并逐段调姿势（内置动作库标签带持握模式）。
