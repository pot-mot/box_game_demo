# 长枪

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)；三模式连段总表见 [`持握模式动作.md`](持握模式动作.md)。

## 武器配置与握持

- id `spear`，中文名「长枪」，`holdModes` 三模式（默认单持；**双手共持为主设计形态**），枪杆沿本地 `+Y` 延伸。
- 主握点位于枪杆下端上方 `poleLen × 0.08`；左手副握点沿枪杆朝枪头方向与主手错开 `poleLen × 0.14`。
- 两个握点都按枪杆本地坐标定位，武器模型原点校正后主手握点落在右手挂点。

## 攻击段（本轮重构：枪轴朝目标，已验收）

**t=0 后引/蓄力 → 中帧 = 刺出/扫击完成（枪轴指向打击方向）→ 末帧 = 持械戒备**；枪头朝向由武器骨骼承担（突刺帧挂点约 `3.0~3.2`，收招回 `1.7`）；0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s），命中窗口轻段 on 0.133s / off 0.253s、重段 on 0.2s / off 0.38s。副握距只有 0.06m，故双手贴握、由躯干前倾与后手位置带出刺距。

| 段 id | 动作 |
|---|---|
| `spear_two_handed_light_1` | 后手撤至胯后（枪尖仍朝前）→ 前手前推、枪尖平刺出 |
| `spear_two_handed_light_2` | 从侧向出手的短刺，落点与轻 1 区分 |
| `spear_two_handed_heavy_1` | 枪杆横向扫击（躯干拧转带枪） |
| `spear_two_handed_heavy_2` | 高位下砸式斜击，落点与前段不同 |
| `spear_two_handed_charge_thrust` | 蓄力后引（枪尖压低）→ 大前倾深刺，肘全程 `rx < 0` |

关键姿势见 `src/character/weapon/attack_pose_edits.ts`。双手副握点由 `weaponSupportGripOffset` 配置；不改变攻击链时长与双手 IK 流程。

## 三持握模式（逐模式连段）

| 模式 | 段前缀 | 动作轨迹 |
|---|---|---|
| 单持（默认） | `spear_one_handed_*` | 单手平刺 / 单手侧刺 / 单手横扫 / 单手斜砸（侧身枪架：根侧转 0.38 rad + 下肢错步；左臂平衡） |
| 双手共持 | `spear_two_handed_*` | 上表五段（含蓄力深刺；侧身枪架：根侧转 0.5 rad，横抱枪杆的手臂获得空间） |
| 双持 | `spear_dual_wield_*` | 右手枪刺 / 侧刺 / 横扫 / 下砸；左手滞后 0.133s 镜像（侧身枪架：根侧转 0.28 rad） |

三模式均采用**侧身枪架**消除手臂-躯干穿模：`root` 关节绕 `+Y` 侧转、`spine` 反向拧转抵消（净胸口偏角约 0.1 rad）、下肢错步（前腿 `rx < 0`）；收招帧根/下肢回零与 idle 衔接。单持/双持段由模板族精修为长枪专属枪轴朝向，双手链为原有手工数据叠加侧身；全部段可在骨骼动画编辑器按「长枪 · 模式 · 段名」逐段调姿势。

## 验收

在骨骼动画模式检查四段（轻 1 / 轻 2 / 重 1 / 重 2，另有自动生成的「蓄力重击」沿用重击一段姿态）：枪轴在打击帧指向目标（不再斜举朝天）；左右手沿杆身贴握。`system.test.ts` 逐帧锁定副握残差 < 0.18m。
