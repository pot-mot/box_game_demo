# 长枪

> 共用规范见 [`动作设计规范.md`](动作设计规范.md)。

## 武器配置与握持

- id `spear`，中文名「长枪」，双手共持，枪杆沿本地 `+Y` 延伸。
- 主握点位于枪杆下端上方 `poleLen × 0.08`；左手副握点沿枪杆朝枪头方向与主手错开 `poleLen × 0.14`。
- 两个握点都按枪杆本地坐标定位，武器模型原点校正后主手握点落在右手挂点。

## 攻击段（本轮重构：枪轴朝目标，已验收）

**t=0 后引/蓄力 → 中帧 = 刺出/扫击完成（枪轴指向打击方向）→ 末帧 = 持械戒备**；枪头朝向由武器骨骼承担（突刺帧挂点约 `3.0~3.2`，收招回 `1.7`）；0.75 倍速（轻段 0.267+0.266s、重段 0.4+0.267s、蓄力突刺 0.6+0.4s），命中窗口轻段 on 0.133s / off 0.253s、重段 on 0.2s / off 0.38s、蓄力突刺 on 0.293s / off 0.6s。副握距只有 0.06m，故双手贴握、由躯干前倾与后手位置带出刺距。

| 段 id | 动作 |
|---|---|
| `spear_light_1` | 后手撤至胯后（枪尖仍朝前）→ 前手前推、枪尖平刺出 |
| `spear_light_2` | 从侧向出手的短刺，落点与轻 1 区分 |
| `spear_heavy_1` | 枪杆横向扫击（躯干拧转带枪） |
| `spear_heavy_2` | 高位下砸式斜击，落点与前段不同 |
| `spear_charge_thrust` | 蓄力后引（枪尖压低）→ 大前倾深刺，肘全程 `rx < 0` |

关键姿势见 `src/character/weapon/attack_pose_edits.ts`。双手副握点由 `weaponSupportGripOffset` 配置；不改变攻击链时长与双手 IK 流程。

## 验收

在骨骼动画模式检查五段：枪轴在打击帧指向目标（不再斜举朝天）；蓄力突刺无反肘，左右手沿杆身贴握。`system.test.ts` 逐帧锁定副握残差 < 0.18m。
