# P4 装备 UI

面向玩家的装备 GUI：**左侧背包网格 + 中央/右侧玩家模型展示 + 环绕式装备槽**，与 P3 物品子系统互通。

## 1. 入口与布局

- 与背包共用一个大面板 `modes/play/equipment_ui/`，`open_inventory`（B）打开背包，`open_equipment`（默认 `E`）打开并聚焦装备视图；两者可在面板内切换标签。
- 布局：
  ```
  ┌───────────── 面板 ───────────────────────────┐
  │ [背包] [装备]                                  │
  │ ┌───────────┐   ┌──────────────────────────┐ │
  │ │ 8×6 网格   │   │ 环绕槽    ○ 主手           │ │
  │ │           │   │   ○ 副手   [3D 模型]  ○ 头 │ │
  │ │           │   │   ○ 胸      ○ 手    ○ 腿   │ │
  │ └───────────┘   └──────────────────────────┘ │
  │  物品细节卡                                     │
  └───────────────────────────────────────────────┘
  ```
- 6 个装备槽 `main_hand / off_hand / head / chest / arms / legs` 绝对定位环绕模型画布。

## 2. 模型展示预览（`equipment_ui/preview.ts`）

```ts
export interface EquipPreviewData {
    mainWeaponId?: string
    offhandWeaponId?: string
    armor: Partial<Record<EquipSlot, string>>
}
export interface EquipmentPreview {
    readonly canvas: HTMLCanvasElement
    setEquipment: (data: EquipPreviewData) => void
    render: () => void
    dispose: () => void
}
export const createEquipmentPreview = (): EquipmentPreview
```

- 独立 `WebGLRenderer`（`alpha: true`，小画布），独立 `Scene` + `PerspectiveCamera` + 与主场景一致的环境光/方向光；**惰性创建**（首次打开背包面板时才创建并挂载），避免 play 启动即多一个 canvas。
- 角色模型：`createCharacterModel(config, 0)` → `equipWeapon({main, offhand?})` / `equipArmor(resolveArmorLoadout(loadout))`，使用默认静止姿态（不启动逐帧动画）。
- 交互：拖拽旋转模型（`pointermove` 改偏航）、滚轮缩放相机距离；每次交互后调用 `render()`**按需渲染**，不启动额外 RAF。

## 3. 装备槽交互

- 从背包网格 `dragStart` 的实例拖到槽：`canEquip(stack, slot)` 校验类别（武器槽收武器、护甲槽收对应 `armorId`）；允许的槽在拖拽时高亮。
- 从槽拖回网格：卸下（写回一个可用格位）；无空位则取消。
- 点击槽：展示该件详情与「卸下」。
- 装备后立即调用 `modes/play/equipment.ts` 的 `applyEquipment` 同步角色战斗数值与外观，并刷新预览。
- `holdMode` 选择器（单持/双手/双持）显示在主手槽旁，仅在武器支持多模式时可选。

## 4. 数据流

- 唯一数据源：`InventoryState`（`inventory.equipment` 记录槽→实例 id）。
- 打开面板时 `preview.setEquipment(derivePublicEquipment(inv))`；任何变更后重算并调用 `applyEquipment` + `preview.setEquipment`。
- 存档：装备映射随 `inventory` 一起持久化（见 P3）。

## 5. 测试

- `equipment_ui/can_equip.test.ts`：槽位与类别校验、交换逻辑（纯函数，不触碰 DOM）。
- 预览模块只做装配，不写单测；由 e2e 覆盖打开/关闭与无报错。

## 6. 依赖

- 依赖 `character/armor` 与 `character/weapon` 目录解析、`entity/character/appearance/model.ts`、`modes/camera_common.ts`、`modes/showcase/scene.ts` 的灯光配置（可抽取共享灯光工厂，若抽取需更新 showcase）。
