# P5 地图、传送点与脱困

## 1. 输入动作

- `open_map`（默认 `KeyM`）：切换地图面板。
- `open_equipment`（默认 `KeyE`，见 P4）。
- `open_inventory`（默认 `KeyB`，见 P3）。
- 脱困**不设快捷键**，走右上角设置菜单（见第 5 节）。

均需同步 `INPUT_ACTIONS` / `ACTION_LABELS` / `ACTION_GROUPS` / `DEFAULT_BINDINGS` / `registry.test.ts`。

## 2. 地图面板（`modes/play/map_ui/`）

```ts
export interface MapPanel {
    setVisible: (v: boolean) => void
    isVisible: () => boolean
    toggle: () => void
    /** 传送选择模式：点击已知传送点返回目标 id 并关闭选择 */
    beginTeleportSelect: (onPick: (teleportKey: string) => void) => void
    update: (data: MapData) => void
    dispose: () => void
}
export interface MapData {
    playerX: number; playerZ: number; playerYaw: number
    bounds: {minX:number; minZ:number; maxX:number; maxZ:number} | undefined
    markers: ReadonlyArray<{key:string; kind:'teleport'|'save_point'; name:string; x:number; z:number; known:boolean}>
}
```

- 用 2D `<canvas>` 俯视绘制：建筑世界包围盒（`building.getAll()` 的体素 bounds）作为地形轮廓底图，标记玩家（三角朝向）、已知传送点（菱形）、存档点（篝火图标）。
- 坐标映射：按 bounds + padding 缩放到画布，保持等比；无建筑时用固定半径。
- 传送选择模式下，鼠标悬停/点击已知传送点即触发回调；未知点灰显不可选。

## 3. 传送点与解锁

- 传送点来源：所有 `kind==='teleport'` 的交互物。每个点有唯一 `key`（保存于交互物：`name` 或 `entityId + name`，推荐在配置中强制 `name` 唯一，key = `name`）。
- `TeleportRegistry`（`modes/play/map_ui/teleport_registry.ts`）：
  - 收集全部传送点（世界坐标 + name）。
  - `known: Set<string>`：首次交互某传送点（或被其信号触发）即解锁；存档于新字段 `teleports?: {known: string[]}`（放在 `modeInfo.play` 或角色上；采用 `modeInfo.play.teleports` 以贴近「世界/模式数据」）。
- 交互传送点：
  - 若 `known` 只有它自己 → 直接提示「传送点已解锁」；否则打开地图进入 `beginTeleportSelect`。
  - 选点后：淡出（全屏 black overlay）→ `characterSystem.setTransform(playerId, {x, y+0.1, z}, rotDeg)` → 清速度 → 淡入。
  - 落点 y 取传送点保存的站立高度（交互物为其自身 groundY + 安全余量）。
- 新存档字段 `TeleportSave = {known: string[]}`，校验层 `.catch([])` 回退。

## 4. 存档点与重生

- 交互 `save_point`：
  1. 回满玩家血（`combat.health = maxHealth`）。
  2. 记录重生点 `{x,y,z,facing}` 到 localStorage 键 `box_demo_respawn`（JSON，带校验回退）。
  3. `cacheSaveData(collectWorldState(...))` 写缓存存档（玩家此刻就在点上）。
  4. 若死亡后从启动屏进入，`play` 模式载入缓存即回到存档点。
- 死亡流程保持现状（`death_screen` → `location.reload()`）；因缓存存档在存档点被刷新，重载后回到存档点。
- `save_point` 首次激活点亮外观并持久化 `on=true`。

## 5. 脱困（右上角菜单）

脱困**不设快捷键**：在右上角设置菜单（齿轮）中选择「传送至最近存档点」，由 `hakoniwa.teleportToNearestSavePoint()` 把玩家传送到最近的**已点燃存档点**；若没有存档点，回退到最近的**已解锁传送点**；都没有则不动作。

- 传送会把玩家 body 平移到目标点（略抬 0.5m）、清零速度并唤醒刚体。
- 「传送至最近存档点」菜单项仅在 `play` 模式注入（`setupSettingsPanel` 第三参）。

## 6. 装配与测试

- 地图面板、传送与脱困逻辑在 `modes/play/hakoniwa.ts` 内装配（输入事件驱动），`updater` 中刷新地图标记。
- 单测：交互目标择优（`interaction/resolve.test.ts`）覆盖传送选点的距离/角度逻辑；地图坐标映射为纯函数（后续可补）。`teleportToNearestSavePoint` 依赖运行时实体，由手动 / e2e 验证。
