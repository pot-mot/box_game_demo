# P3 背包与物品子系统

背包领域层 `src/inventory/`（纯 TS，不依赖 `entity/` / `modes/`），掉落物实体 `src/entity/item/`，背包 UI 与掉落/拾取编排在 `src/modes/play/inventory_ui/`。

## 1. 物品定义（`inventory/items.ts` / `catalog.ts`）

```ts
export const ITEM_CATEGORIES = ['weapon', 'armor', 'consumable', 'material', 'key'] as const
export type ItemCategory = typeof ITEM_CATEGORIES[number]

/** 俄罗斯方块形状：每行一个字符串，'#' 为占格；行数即高度，最长行即宽度 */
export interface ItemDef {
    readonly id: string
    readonly name: string
    readonly category: ItemCategory
    readonly shape: readonly string[]
    readonly maxStack: number
    /** 可装备武器：指向 weapon 模型 id（weapon_class.ts 的 `*_WEAPON_MODELS`） */
    readonly weaponId?: string
    /** 可装备护甲：指向护甲预设 id */
    readonly armorId?: string
    /** 由护甲件直接映射的装备槽（缺省由 armorId 解析） */
    readonly equipSlot?: EquipSlot
    /** 掉落物世界网格尺寸 */
    readonly dropSize: readonly [number, number, number]
    readonly description: string
}

export const ITEM_DEFS: readonly ItemDef[]
export const findItemDef = (id: string | undefined): ItemDef | undefined
```

## 2. 背包与物品实例（`inventory/types.ts` / `inventory.ts`）

```ts
export const EQUIP_SLOTS = ['main_hand', 'off_hand', 'head', 'chest', 'arms', 'legs'] as const
export type EquipSlot = typeof EQUIP_SLOTS[number]

export interface ItemStack {
    instanceId: string
    defId: string
    count: number
    /** 背包格位（在装备槽 / 容器 / 世界中的实例无此字段） */
    grid?: Placement
}

export interface InventoryState {
    width: number
    height: number
    stacks: ItemStack[]
    /** 槽位 → 物品实例 id（装备中的物品仍在 stacks 中，用于卸下时找回定义与增强） */
    equipment: Partial<Record<EquipSlot, string>>
}

export const createInventory = (): InventoryState          // 默认 8×6
export const addItem = (inv, defId, count, instanceIdFactory): AddResult
export const removeAt = (inv, instanceId)
export const moveStack = (inv, instanceId, placement): boolean
export const equipStack = (inv, instanceId, slot): EquipResult
export const unequipSlot = (inv, slot): EquipResult
export const equippedStacks = (inv): ReadonlyArray<{slot: EquipSlot; stack: ItemStack}>
export const mergeAllowed = (a: ItemStack, b: ItemStack): boolean  // 同 defId 且未满
```

- `addItem` 自动寻找可放置位置（`findPlacement`），支持堆叠合并；背包满返回 `{ok:false, reason:'full'}`。
- 装备：若目标槽已占则交换；武器 → `main_hand`/`off_hand`，护甲 → 对应槽；校验类型匹配（武器 `weaponId`、护甲 `armorId`/`equipSlot`）。
- 所有变更函数返回新状态或就地修改（实现采用就地修改 + `changed` 标记，避免每帧分配；UI 读取）。

## 3. 与装备/战斗互通（`modes/play/equipment.ts`）

- `applyEquipment(characterSystem, playerId, inventory, slot)`：
  - `main_hand`：`updateCharacterConfig(id, {}, {weaponId, ...})` 走 `setCombatWeapon`；持握模式重解析（复用 `setHoldMode`）。
  - `off_hand`：`setCombatOffhand`。
  - `head/chest/arms/legs`：组装 `ArmorLoadout` → `setCombatEquipment` + `model.equipArmor`。
- 卸下：恢复该槽为空（护甲传 `{}`；副手 `null`；主手回默认武器 `DEFAULT_WEAPON_ID`）。
- 存档以角色 `attack/offhand/armor/holdMode` 为准；`inventory.equipment` 记录实例，加载后据此校正（旧档无 inventory 时不动）。

## 4. 掉落物实体（`entity/item/`）

```ts
export interface DroppedItemConfig { defId: string; count: number }
export interface DroppedItemEntity { id: number; defId: string; count: number; mesh: Mesh; body: RigidBody; rowText: string }
export interface ItemEntityContext extends EntityInfoSource {
    drop: (defId: string, count: number, x: number, y: number, z: number) => {id: number}
    getSaveItems: () => SavableItem[]
    loadSaveItems: (items: SavableItem[]) => void
    registerInteractionProvider: (provider: InteractionProvider) => void
}
export const setupItemEntities = (scene: Scene, shared: SharedWorld): ItemEntityContext
```

- 网格：按 `ItemDef.dropSize` 生成小立方体（共享材质，单例 `getSurfaceMaterial('rusty_iron')` 或按类别），`scale` 与 `shape` 无关（可加发光）。
- 物理：dynamic body + cuboid collider，类别 `item`（`collision_category.ts` 新增 `item = 1 << 13`），与 ground/building/interactable 碰撞，不与角色碰撞（角色走近自动拾取）。
- 拾取：实现 `InteractionProvider`，提示「拾取」；激活 → 尝试 `addItem`，成功则移除实体，失败提示「背包已满」。
- 旋转/漂浮：每帧小幅度自转（`preSync` 或 updater）。

## 5. 背包 UI（`modes/play/inventory_ui/`）

- 打开方式：输入动作 `open_inventory`（默认 `KeyB`）切换显隐；打开时释放鼠标（退出指针锁定/暂停相机拖拽，复用相机 `setEnabled` 类似能力，如无则忽略）。
- 布局：左侧为 `width×height` 格子网格（DOM `position:grid` 或绝对定位单元格），每格 `INVENTORY_CELL_PX`；物品以绝对定位 `div` 覆盖其占用的格子，尺寸 = 形状包围盒 × 格宽。
- 形状显示：用 CSS `clip-path` 或每格一个内层方块渲染 `#` 掩码，直观呈现俄罗斯方块形状。
- 交互：
  - 拖拽移动：`pointerdown` 拎起（高亮合法/非法落点，实时用 `canPlace` 校验），`pointerup` 落位；非法则回原位。
  - 旋转：拖拽中按 `R` 循环 `rot`。
  - 右键/双击装备：按槽位自动选择（武器→主手，护甲→对应槽）；已装备物品在装备面板可卸下。
  - 悬停显示细节卡（名称/描述/数量/装备按钮/丢弃按钮）。
- 面板为独立 DOM 工厂 `createInventoryPanel(host): InventoryPanel {update,setVisible,destroy,open}`，脏检查刷新，退出模式销毁并移除注入样式。
- 丢弃：把物品实例转为世界掉落物（在玩家前方 1.2m、脚下高度生成），从背包移除。

## 6. 容器（箱子）

- `chest` 持有独立的 `InventoryState`（`InteractableEntity.container`，6×4 网格，俄罗斯方块布局）。
- 交互打开**双栏容器面板**（`modes/play/container_ui/panel.ts`）：左栏玩家背包、右栏箱子，两栏共用 `inventory_ui/grid_render.ts` 的渲染；支持栏内拖拽移动、跨栏拖拽存取、双击快速转移、拖拽中按 `R` 旋转。
- 跨栏移动走 `transferStack(from, to, instanceId, placement?)`：保留实例 id 与数量，优先指定格位否则自动寻位；源物品若为装备态则先解除装备映射。
- 箱子内容随交互物存档持久化（`InteractableSaveEntry.container`）；新放置的箱子默认放入少量物资。

## 7. 存档

背包持久化在 **`modeInfo.play.inventory`**（非 character 存档）；`main.ts` 保存时把 `hakoniwa.getSaveData()` 并入 `modeInfo.play`：

```ts
export interface InventorySaveData {
    width: number
    height: number
    items: Array<{instanceId: string; defId: string; count: number; grid?: {x:number;y:number;rot:number}}>
    equipment: Partial<Record<EquipSlot, string>>
}
// ModeInfoJSON.play 增加 inventory?: InventorySaveData 与 teleports?: string[]
```

- `validation.ts`：`inventory` / `teleports` 均 `.optional().catch(undefined)`，逐字段 `.catch`；非法格位由 `inventoryFromSave` 重新自动归位，未知 `defId` 丢弃，未知装备槽丢弃。
- 掉落物作为独立实体类型 `SavableItem`：

```ts
export interface SavableItem { type: 'item'; config: {defId:string; count:number}; position: Vec3JSON; quaternion: QuatJSON }
```

- `SAVE_FORMAT_VERSION` 递增到 8 并注释说明；`EntitySourceMap` 加 `'interactable'` 与 `'item'`。
