# P2 交互物子系统

交互物是 `entity/interactable/` 下的独立实体系统（`EntityInfoSource` + `EntityTickHandler`），在 `main.ts` 注册进 `systems` 与 `bodyProviders`，并作为 `InteractionProvider` 接入 play 交互。

## 1. 类型

`kinds.ts`：

```ts
export const INTERACTABLE_KINDS = [
    'save_point', 'teleport', 'switch',
    'push_door_single', 'push_door_double', 'gate',
    'chest', 'elevator', 'breakable',
] as const
export type InteractableKind = typeof INTERACTABLE_KINDS[number]
export const INTERACTABLE_LABELS: Record<InteractableKind, string> = {...中文名...}
```

`types.ts`（判别式联合，配置可存档）：

```ts
export interface InteractableBaseConfig {
    kind: InteractableKind
    /** 外观材质 */
    material: SurfaceMaterialId
    /** 视觉/碰撞尺寸 [宽, 高, 深]（米） */
    size: [number, number, number]
    /** 信号通道：开关发布、门/闸门/升降梯订阅；空串 = 不联动 */
    channel: string
}

export interface SavePointConfig extends InteractableBaseConfig { kind: 'save_point'; name: string }
export interface TeleportConfig extends InteractableBaseConfig { kind: 'teleport'; name: string }
export interface SwitchConfig extends InteractableBaseConfig { kind: 'switch'; mode: 'toggle' | 'momentary' }
export interface PushDoorConfig extends InteractableBaseConfig { kind: 'push_door_single' | 'push_door_double' }
export interface GateConfig extends InteractableBaseConfig { kind: 'gate'; travel: number; speed: number }
export interface ChestConfig extends InteractableBaseConfig { kind: 'chest'; capacity: number }
export interface ElevatorConfig extends InteractableBaseConfig { kind: 'elevator'; travel: number; speed: number }
export interface BreakableConfig extends InteractableBaseConfig {
    kind: 'breakable'
    health: number
    /** 可破坏本道具的攻击来源类别；命中不在列表内则无伤害 */
    breakableBy: readonly BreakableSource[]
}

export type InteractableConfig =
    | SavePointConfig | TeleportConfig | SwitchConfig | PushDoorConfig
    | GateConfig | ChestConfig | ElevatorConfig | BreakableConfig

export const BREAKABLE_SOURCES = ['melee', 'ranged', 'explosion', 'roll'] as const
export type BreakableSource = typeof BREAKABLE_SOURCES[number]
```

每个配置提供一个 `defaultInteractableConfig(kind): InteractableConfig`（用于 edit 生成/面板回退），所有数值取自 `constants.ts`。

## 2. 运行时状态（`InteractableEntity`）

```ts
export interface InteractableEntity {
    id: number
    config: InteractableConfig
    group: Group              // 视觉根（含可动子节点）
    body: RAPIER.RigidBody    // fixed / kinematicPositionBased
    colliders: RAPIER.Collider[]
    /** 动画进度 0..1（门扇开合 / 闸门升降 / 升降梯行程） */
    progress: number
    /** 目标进度（0=关/下，1=开/上）；开关/信号驱动 */
    target: number
    /** 开关当前状态（switch） */
    on: boolean
    /** 容器内容（chest）——独立格位背包（俄罗斯方块布局，见背包文档） */
    container: InventoryState
    /** 生命（breakable） */
    health: number
    dead: boolean
    rowText: string
}
```

## 3. 行为接口（`behavior/`）

```ts
export interface InteractableBehavior {
    /** 是否可被玩家交互（默认 true；breakable=false） */
    interactable: boolean
    /** 交互提示；返回 undefined 表示当前不可交互 */
    prompt: (e: InteractableEntity) => string | undefined
    /** 玩家交互生效 */
    interact?: (e: InteractableEntity, ctx: InteractableRuntimeContext) => void
    /** 信号（channel on/off）到达 */
    onSignal?: (e: InteractableEntity, on: boolean, ctx: InteractableRuntimeContext) => void
    /** 每帧推进（动画、载客、破坏判定） */
    update: (dt: number, e: InteractableEntity, ctx: InteractableRuntimeContext) => void
    /** 受到攻击（仅 breakable 有效） */
    onAttacked?: (e: InteractableEntity, source: BreakableSource, amount: number, ctx: InteractableRuntimeContext) => void
}
```

`BEHAVIORS: Record<InteractableKind, InteractableBehavior>` 登记全部 9 类。

`InteractableRuntimeContext` 提供：`setSignal(channel, on)`、`player: InteractablePlayerAccess | undefined`、`hooks: InteractableHooks`（`onSavePoint` / `onTeleport` / `onOpenChest` / `onBreak`）、`despawn(id)`。跨领域动作一律经 `hooks` 注入（由 `main.ts` / play 侧提供），交互物领域不依赖角色 / 背包 / 地图模块。

## 4. 各类行为

| 类型 | 交互 | 行为要点 |
|------|------|----------|
| `save_point` | 交互 | 播放篝火点燃动画；回满血、记录重生点（世界坐标 + 朝向）、写 localStorage 存档（复用 `cacheSaveData`）；提示「点燃篝火」。已激活的点换色。 |
| `teleport` | 交互 | 打开地图/传送面板（见 P5）；自身注册为已知传送点；提示「传送」。 |
| `switch` | 交互 | `toggle`：翻转 `on` 并发布信号；`momentary`：交互按下置 on，交互结束/离开后置 off（用 progress 计时）。提示「开启/关闭」。 |
| `push_door_single` | 交互 | `target` 0↔1 切换，门扇绕铰链旋转 90°；`progress` 向 `target` 逼近；门完全打开时禁用碰撞体，关闭过程启用。提示「推开/关闭」。信号可远程驱动。 |
| `push_door_double` | 交互 | 双门扇对称旋转；其余同单推门。 |
| `gate` | 交互 | 垂直闸门沿 +Y 移动 `travel`；信号驱动；移动中的闸门碰撞体随视觉同步（kinematic body `setNextKinematicTranslation`）；关闭到位时实体挡路。提示「开启/关闭闸门」。 |
| `chest` | 交互 | 打开**双栏容器 UI**（玩家背包 ↔ 箱子，均为俄罗斯方块网格）：拖拽跨栏存取、双击快速转移；盖子开合动画。提示「打开箱子」。 |
| `elevator` | 交互 | 平台在两高度间往返；kinematic body；`PlayerAccess` 检测玩家站在平台上时按平台位移平移玩家（保持 `isOnGround`）；信号驱动。提示「启动升降梯」。 |
| `breakable` | 无 | 不可交互；受攻击来源在 `breakableBy` 内时扣血；归零后播放碎裂（复用 `box/destruction` 的碎片系统或缩放消失），`despawn` 并掉落配置物资。 |

**信号总线**：`SignalBus` 是系统内 `Map<string, boolean>`；`switch`/`save_point` 可发布，门/闸门/升降梯订阅。同通道多个订阅者同时响应。加载存档后重建信号状态。

## 5. 可破坏道具与战斗集成

`breakable` 通过扩展战斗执行器接收伤害：

1. `character/combat/targetable.ts` 增加来源类别常量：
   ```ts
   export const ATTACK_SOURCE_KINDS = ['melee', 'ranged', 'explosion', 'roll'] as const
   export type AttackSourceKind = typeof ATTACK_SOURCE_KINDS[number]
   ```
2. 新增世界受击目标接口（`character/combat/world_targets.ts`，纯类型）：
   ```ts
   export interface WorldDamageTarget {
       readonly key: number          // 全局唯一（如 -entityId）
       readonly x: number; readonly y: number; readonly z: number
       readonly hx: number; readonly hy: number; readonly hz: number
       readonly yaw: number
       readonly dead: boolean
       /** 命中：自行按 source 与 breakableBy 决定是否扣血；返回是否消费本次命中 */
       onAttacked: (source: AttackSourceKind, damageType: DamageType, amount: number, dirX: number, dirZ: number) => boolean
   }
   ```
3. `CharacterEntitySystem` 增加 `registerWorldDamageTargets(provider: () => readonly WorldDamageTarget[])`，`world.ts` 持有并在三个命中路径消费：
   - **近战** `melee_executor`：命中窗口内，除角色外的世界目标用 `obbIntersect(weaponOBB, yawOBB(target...))` 判定，命中调用 `onAttacked('melee', weapon.damageType, damage, dirX, dirZ)`。
   - **远程** `ranged_executor`：子弹每步与世界目标做 OBB/球相交，命中调用 `onAttacked('ranged', damageType, damage, ...)` 并按是否消费决定是否消失。
   - **爆炸** `explosion`：范围内世界目标调用 `onAttacked('explosion', ...)`。
   - **翻滚**：`world.ts` 在玩家 `rolling` 状态且处于无敌帧窗口内，对世界目标做胶囊近接判定，命中调用 `onAttacked('roll', 'physical', ROLL_BREAK_DAMAGE, dirX, dirZ)`。
4. `breakable` 行为在 `onAttacked` 中：
   - `source ∉ breakableBy` → 返回 false（不消费，例如子弹继续飞）；
   - 否则扣血，更新变色/抖动；归零 → `dead=true`，进入摧毁流程，返回 true。

> 该设计让「哪些攻击类型能破坏」由数据（`breakableBy`）决定，逻辑集中在交互物系统，战斗系统只负责投递来源与几何判定。

## 6. 视觉（`mesh.ts`）

- 复用 `entity/character/appearance/mesh_builder.ts` 的 `createMeshBuilder()` 构建立方体组合，材质取 `getSurfaceMaterial(config.material)`。
- 可动部件（门扇、闸门、升降梯平台、箱盖）作为 `group` 的子节点，行为只改子节点 local transform。
- 破坏后或销毁时 `builder.dispose()`；共享材质不得 dispose。

## 7. 物理

- `save_point` / `teleport` / `switch` / `chest`：固定 body（`fixed`），单个 cuboid collider，类别 `interactable`。
- `push_door_*` / `gate`：`kinematicPositionBased` body，开门/上升时按进度 `setNextKinematicTranslation`，并在完全打开时通过 collider setter 禁用碰撞（或把 collider 移到门后）。
- `elevator`：`kinematicPositionBased` 平台 collider，尺寸 = `size`，玩家可站立。
- `breakable`：固定 body，cuboid collider，类别 `interactable`；破坏后移除 collider。
- 所有碰撞体必须 `categoryCollisionGroups(INTERACTABLE_COLLISION_GROUP, mask, 'interactable')`；`collision_category.ts` 新增类别位 `interactable = 1 << 12`，`physics/constants.ts` 新增 `INTERACTABLE_COLLISION_GROUP` 与掩码（与 ground / character / item / building 交互）。

## 8. 存档

新增实体类型 `SavableInteractables`：

```ts
export interface SavableInteractable {
    type: 'interactable'
    config: InteractableConfig
    position: Vec3JSON
    yawQuarter: number
    progress: number
    target: number
    on: boolean
    container?: InventorySaveData   // chest 内容（缺省 = 空容器）
    health: number
}
```

- `save_load/validation.ts` 增加判别联合分支与逐 kind schema（`.catch` 回退默认配置）。
- `EntitySourceMap` 增加 `'interactable': InteractableContext`。
- 载入时未知 kind 条目丢弃；`container` 中未知 defId / 非法格位由 `inventoryFromSave` 安全处理。

## 9. 编辑面板（`ui/panel.ts`）

选中交互物后显示：类型（只读）、材质、尺寸、通道、按类型的专属参数（travel/speed/health/breakableBy 多选/name）、位置与 90° 偏航、删除，以及「触发交互」按钮（edit 主动触发）。
